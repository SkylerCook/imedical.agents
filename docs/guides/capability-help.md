# skill / Agent 帮助

本协议适用于框架自有 skill 和 canonical Agent，统一帮助请求的处理方式；具体用途、输入、参数和执行边界仍以各自的 `SKILL.md` / `AGENT.md` 及其明确引用为准。第三方 vendor 沿用上游契约，底层脚本的 CLI 参数由脚本自身说明。

## 发起帮助请求

在宿主支持的技能选择器或原生调用中追加 `--help`，或直接说“查看某技能的用法”“介绍某 Agent 如何使用”：

```text
$bos-demand-entry --help
查看 iris-deploy 的用法
介绍 coordinator-agent 的用途、输入和调用示例
```

这些是给 Agent 的请求，不是 PowerShell 命令。宿主不支持 `$名称` 时，直接点名，或让 Agent 读取真实定义并展示帮助。init 技能没有日常薄索引时，直接读取其插件内 `SKILL.md`。

默认给简明帮助；“完整帮助”“全部参数和限制”才展开完整说明。引用资料或讨论实现中出现的 `--help` 字样不自动切换当前任务，只有用户明确请求所选入口的帮助时进入本分支。

## Agent 处理协议

1. **先分流帮助。** 读取当前入口真实定义和本协议，跳过定义中后续的业务前置、初始化及执行步骤。帮助请求同时带 `--commit`、部署对象或其他执行参数时仍只展示帮助，说明“本次仅展示帮助，未执行附带动作”；不把这次请求转换为业务执行授权。
2. **仅取说明事实。** 按需读取直接相关的能力说明或公开参考。项目缺少配置、插件未启用或工具未连接，都不阻塞帮助；前提只按定义介绍，不检查现场。帮助阶段不读取业务代码、草稿、业务记忆、profile 或私有连接信息，不运行状态探测、初始化、workflow、Git 同步/提交、部署及远程调用，不生成业务产物或 task run。定位 Overlay 文档所必需的 `capability.json` 是路径元数据，可只读。
3. **按下方结构展示。** 摘要必须来自当前定义；只列明确声明的用户入口参数，区分用户请求参数和底层 CLI 参数。没有用户参数时说明应提供的自然语言信息，不借用其他技能的 `--plan` / `--commit`。Agent 角色介绍职责、输入输出和调用方式，不为内部角色制造参数表。
4. **展示后结束。** 不继续业务流程，不要求用户为看帮助先配置连接或启用插件，也不追问是否执行。实际执行须由后续明确任务进入原流程。

## 帮助内容

默认包含以下内容，按复杂度合并成短段落或小表格，无需固定套用标题：

- 用途、适用场景和必要前提。
- 用户需提供的信息，以及常用的已声明参数；参数较多时链接真实定义中的完整参数表。定义未声明参数时使用自然语言示例。
- 2–3 个可理解的调用示例，保持 skill 与脚本调用层次一致；示例中的占位信息明确标记，不编造业务编号、连接或执行结果。
- 预期输出与主要操作边界，特别说明正常执行涉及的写入或授权条件；帮助本身只展示说明。
- 末尾一句“更多场景与完整流程见使用指南”，优先链接[使用指南](capability-guide.md)中该 owner 的实际章节；仅在需要时查[能力目录](capability-catalog.md)定位，不预先加载全部手册。

xc 和尚无独立指南章节的 Agent，末尾链接本页及真实定义，不构造不存在的章节。源仓维护专用 skill 仍只服务源仓，不因帮助协议进入项目部署范围。用户要求完整帮助时，展开定义中全部已声明参数、组合限制和必要前提，不扩大资料读取或执行范围。

## 路径与更新

- 源定义中的相对链接以解析后的真实源文件所在目录为基准。standard 工程的协议通常位于 `.agents/docs/guides/capability-help.md`。
- Overlay 未映射 `docs/` 时，先从当前工程 `.agents/capability.json` 的显式 `CapabilityRoot` 定位同一 `docs/guides/capability-help.md`，指南也从该能力包读取。沿[已有 Overlay 路径规则](../workspace-overlay.md)解析，不扫描父目录或相邻工程，不创建额外映射或复制协议。
- 帮助中的文件链接使用实际可访问的路径；协议或真实定义缺失时报告能力包不完整，提示按[正常更新流程](../update-agents.md)修复并结束帮助，不启动业务步骤补救。
- 协议、skills 和 Agents 沿既有 sparse 路径分发。新旧薄索引均继续读取真实定义，本能力不更改薄索引模板、插件启用集合或更新器编排。宿主目录链接读取同一集合；独立的用户级复制副本仍由原分发流程维护。

具体安装、standard 更新、Overlay 的共享更新及模块刷新步骤见[更新 Runbook](../update-agents.md#统一-skill--agent-帮助)。文件落盘、入口可达与实际 Agent 行为应分别验证。
