## 来源与口径

- v8.4～v9.1 于 2026-11-03 按对应标准版 corePro 源码补强：v8.4 2850 项、v8.5 3141 项、v9.0 3426 项、v9.0.2 3705 项、v9.1 4796 项。读取源码 XML 中全部对象、TXT 类声明、类型明确的例程及 Web 资源；排除独立产品、备份、示例和部署路径不明的候选。v9.1 的 tag 与 trunk 标准版对象集合一致。
- v8.3 是按用户确认的 8.3 实例已取回代码重建的范围清单，不是官方完整标版或可导入的源码包。由 v8.4 范围采集成功的 903 项，加后续补取新增的 7 项组成，共 910 项（333 CLS、2 MAC、575 CSP/Web）；重复成功项 7 项内容摘要一致。纳入前逐项核对成功回执、文件大小和 SHA-256；未取回条目不纳入，也不据此认定该版本不存在这些对象。TXT 仅保存对象身份，不含源码、连接信息或私有回执。生成日期不是源码版本日期；使用前仍需按目标实例补齐范围、核对 Web 路径。
- v8.4～v9.1 合并原清单与对应标准版源码证据；v9.2 是离线扫描来源 checkout 生成的全仓清单。版本标签与生成时刻不是服务器当前版本证明，TXT 保留对象集合，来源日期不代表版本真实性或完整性。
- CLS／MAC／INC／INT 对象使用完整扩展名，Web 项使用以 / 开头的完整虚拟路径。v9.2 按 Class 声明取真实类名，既有版本的目录换算差异在比较时解释，不据名称自动认定删除。
- 没有对应版本时，明确核对备选清单和实际所需范围；不自动按较高版本扩张导出范围。项目增补条目和当前实例私有内容留目标工程，不自动发布到能力包。

补强边界：v8.4 有 2 项、v9.1 有 1049 项原清单对象未在对应源码目录找到，保留待实例验证；其余受核对版本均有源码对象证据。每个版本另有 69 个候选因例程类型或 Web 部署路径不明未自动纳入。Web 统一基准为 `/imedical/web/`，来源 XML 也含 `/dthealth/web/`；医院路径不同需显式映射。v9.1 未获源码佐证的旧路径继续保留并要求确认。上述证据仅确认对象身份，不证明当前服务器存在、所在 Namespace 或依赖完整性。8.3、9.2 无此次对应来源，保持原范围。

## 清单格式与迁移

TXT 是唯一维护源，一行一个对象；UTF-8（可含 BOM）、LF/CRLF 均可，空行和以 # 开头的整行注释忽略。后端必须含 .cls/.mac/.inc/.int 扩展名，Web 必须以 / 开头。禁止通配符、相对路径和重复对象（含大小写冲突）；不要粘贴表头、备注列或 CSV。共享表格只导出对象列，备注与版本来源写在本 README 或项目说明中。

原 ProjectItem XML 已删除，框架与人工工具不再读取 XML 范围清单；Git 历史仅用于追溯，不维护兼容副本。格式迁移时已去除历史重复条目；之后的源码核对扩大了 v8.4～v9.1 范围并新增 v9.0.2，数量以上文为准。新任务直接引用版本 TXT；旧任务的范围与运行时摘要不可改写，用旧工具完成后再升级，或保存已有结果并用新版新建任务。实际源码 XML 包不属于范围清单，不受此迁移影响。

- [iris-xml-export](../../../../plugins/coding-iris-plugin/skills/iris-xml-export/SKILL.md)：Agent 与用户确认准确对象集合后生成可导入 XML 包，支持图片等二进制 Web 资源，逐项核对身份与载荷。
- [项目开发协议](../../../../plugins/coding-iris-plugin/references/project-demand-development.md)：已确认 project＋按需上下文时建立开发基线，日常只刷新需求集合，部署前重新同步。提交与部署分别核对授权。

当前 CLI 从 CapabilityRoot 的 plugins/coding-iris-plugin/scripts/iris-tools/ 定位，参数以 baseline-catalog.js、code-baseline.js 和 xml-export.js 的 --help 为准；不再依赖用户级技能目录或旧 QTZ 导出入口。共享清单变更须另有审查及发布依据，普通采集不会回写本目录。
