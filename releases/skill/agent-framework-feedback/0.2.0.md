# agent-framework-feedback 0.2.0

将默认动作改为 `taskKind=business-demand` 在用户验收后的只读反馈审查；框架维护使用独立生命周期，不创建需求验收状态，也不触发或提示 feedback。经验新增、命中更新、framework feedback 和 rule 提升分别等待用户授权。

## Migration

已部署工程更新 skill 后，先按 `taskKind` 分类；只有业务需求进入 `accepted` 后报告候选和命中，并按用户授权执行具体写入。
