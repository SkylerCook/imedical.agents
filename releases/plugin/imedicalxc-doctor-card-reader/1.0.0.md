# imedicalxc-doctor-card-reader 1.0.0

初始版本。新增 HIS 医生站读卡设备接入配置 skill，覆盖：

- 根据设备厂商、型号动态解析 `ct_dic_commondicttype` 目录，不写死目录 id。
- 生成厂商、型号两条 `ct_dic_commondict` 通用字典 SQL，操作人通过 `hos_user_account.code='admin'` 动态获取。
- 生成 `ct_pa_card_hard_manager` 设备接口参数配置 SQL，关联厂商、型号和版本字典 id。
- `run_prefix` 默认 `C:/Program Files (x86)/Java/jdk-1.8/bin/java.exe`；目标库现状明确不同时先确认后覆盖。
- 提供查询、插入、验证三段 SQL 模板，以及 `py_code` / `wb_code` 推导规则、防重复规则和跨项目适配清单。
- 默认只生成 SQL；写库需明确授权，连接信息不进入插件。

当前仅支持 SQL 操作。后续读卡相关操作按独立 skill 扩展，避免与设备配置写库流程耦合。
