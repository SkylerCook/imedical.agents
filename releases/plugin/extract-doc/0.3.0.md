# 文档解析输出接入项目目录治理

新增 `document-ingest` 目录声明，已明确接入治理的项目默认通过 canonical 目录解析器输出到 `docs/modules/interfaces/<doc-name>/`。未接入或已关闭治理时保持 `docs/interface/<doc-name>/`，不要求 Node.js；显式 `--output-root` 始终优先。已启用治理但配置、owner 或解析器无效时停止，避免静默写入另一位置。

输出文件名、schema 和现有显式调用保持兼容。更新不启用项目治理、不迁移历史文档；首次接入和已有材料搬移仍需具体计划授权。业务插件复用本 owner 的目录契约和实际返回路径。
