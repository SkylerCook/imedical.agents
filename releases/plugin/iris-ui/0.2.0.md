# 明确 CSP＋HISUI 适配层并强依赖公司 UI 规范

正式依赖 imedical-ui 0.1.x，与 coding-iris-plugin 0.20.x 一起组成接入前提。公司规范、共性/差异及截图/浏览器评审归通用层；本插件保留公共head/body、资源链、HISUI布局生命周期和技术验证。短名、已有日常入口和只读测量API保持；不创建未来Java/HTML适配插件。commit为实施源仓基线。

## Migration

原0.1.0已启用工程需在既有注册/profile中核对并接入imedical-ui，再按标准框架流程更新共享capability和模块Context。显式disabled及启用集合冲突保持待处理，不通过机械setter覆盖。缺依赖时UI入口不代表可用，更新器整体退出0也不能替代逐项状态检查；frontend直接读rule同样执行统一依赖约束。无旧文件删除、业务/公共CSS改动或连接配置迁移。原始公司资料推送及正式分发按授权单独执行。
