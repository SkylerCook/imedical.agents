# IRIS UI 专项能力初版

提供 UI 标注到代码的任务流程、主题适用性与公共能力核对、布局及初始化故障参考、脱敏案例、任务记录模板和只读尺寸采集辅助。编码、HISUI vendor、部署与测试状态继续复用原 owner。commit 为实施源仓基线。

通过正常框架更新取得插件，默认 available；明确接入时核对 coding-iris-plugin 兼容版本，按共享能力更新与模块 Context 刷新的原流程执行，由框架生成受管薄索引。手工同步开发版不作为正式部署完成。纯 init 不生成日常入口，项目自定义配置保留。无连接配置迁移、旧文件清理、业务页面更新或自动启用。技术验证与用户验收分别记录，真实 HIS 场景须在获授权工程补验。
