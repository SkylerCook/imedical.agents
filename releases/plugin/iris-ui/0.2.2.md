# 补齐跨主题共性实施与只读条件扫描

UI 规则覆盖修改前归类、共享入口、最终 diff 的主题限定与直接调用者核对，并以 CSS 优先级、控件初始化和动态阶段核对既有验收基准。现有任务表承接共性落点、差异依据和兼容基准，匿名案例说明整块业务适配被主题门控的风险。

新增 check-theme-scope.js，使用现有 Workspace/Overlay 路径解析，仅扫描显式指定源码并输出候选及覆盖限制。候选不自动判违规，不修改源码，不接入 Git 硬阻断。依赖 imedical-ui 0.1.1 与 coding-iris-plugin 0.20.4。commit 为实施源仓基线。

沿正常框架更新分发插件脚本；Overlay 共享能力更新一次，再由模块管理入口以 -NoPull 刷新。无配置迁移、业务资源发布或旧文件清理；源仓结果不代表下游已升级，跨平台结果和业务验收分别取证。
