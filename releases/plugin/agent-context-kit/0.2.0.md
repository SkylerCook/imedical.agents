# agent-context-kit 0.2.0

新增通用 schema 2.0 run/plan 模板与 Node 调度器验证入口；历史 schema 保持只读兼容。新增互斥 `taskKind`，业务需求使用验收/feedback 生命周期，框架维护使用独立 `maintenance-complete` 生命周期，运行时拒绝跨生命周期 transition。

## Migration

已部署工程通过标准更新器同步能力包。保留现有 schema 1.0–1.2 运行目录只读不变；仅新 run 使用 schema 2.0 和 `agent-orchestrator.js`。新计划必须明确 `taskKind`；`feedbackReviewApplicable` 由任务类型派生，不能独立开启。
