# agent-context-kit 0.4.2

修复 Windows 8.3 短路径与 Git 返回的长路径混用时，task-handoff 将本地交接目录误判为仓库外，以及 Overlay GitRoot、Junction 目标误判。Git 查询和排除规则使用 Git 仓库内相对路径；已有目录的身份比较使用解析后的真实路径。嵌套项目的交接排除规则和状态记录也按仓库相对路径处理。

正常更新能力包即可使用修复。已有交接文档、Git 跟踪状态和项目入口不自动修改；无兼容清理。commit 为实施基线，发布提交由 Git 历史追溯。
