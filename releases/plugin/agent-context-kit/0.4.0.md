# agent-context-kit 0.4.0

新增 task-handoff 通用接续入口：需求按需启用后持续维护，明确交接生成历史快照；新会话读取项目材料、核对 Git/内容现场与已有证据后继续授权范围内工作。轻量 Node 工具提供目录、发现、检查点、快照和结构检查，不要求创建正式 run，不负责并发控制或授予外部操作权限。
