# Codex 原生 Agent 适配

coding-agent-adaptation 默认仅适配 Skill，显式 --agent 进入 Codex 原生 Agent 操作分支；根生成器读取 canonical AGENT.md，生成项目 TOML 并保护自定义内容。技能发现与原生角色加载分别验证，继承父会话权限和模型。

## Migration

更新能力包后显式执行 sync-runtime-skills.js --agent 或更新器 -RuntimeAdapter Codex -Agent，之后普通更新维护已有受管文件。不自动修改项目信任或用户配置；Overlay 调用 CapabilityRoot 下的生成器。具体命令见 docs/coding-agent-adaptation.md。commit 为实施基点。

WorkBuddy / CodeBuddy 原生适配已加入既有 --agent 入口，共用 .codebuddy/agents 薄入口；PowerShell 显式 -RuntimeAdapter WorkBuddy（或 CodeBuddy）-Agent，默认仍为 Skill。源定义只维护 AGENT.md，客户端实际调用待验。
