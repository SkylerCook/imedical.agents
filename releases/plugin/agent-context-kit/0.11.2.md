# 插件入口隔离与接入结果核实

项目插件管理统一读取初始化 source：无 initSkill 的插件从自身 entry 进入。单 owner 生成保护其它插件、未落盘来源、自定义内容与链接；已声明且可证明未定制的旧受管入口保留兼容清理。发现入口生成或验证失败时保留原状态，不记录新的启用成功。

profile 缺失后的正常写入复用安装状态保留历史资源需求，仅记录实际已知或本次明确的状态；缺行历史不被默认 available 覆盖，也不推断为 enabled。资源需求与启用状态分别核对，沿既有入口继续操作。

已部署项目正常更新本插件及根 scripts 后刷新已启用索引。无新增用户参数、配置或业务资料清理。
