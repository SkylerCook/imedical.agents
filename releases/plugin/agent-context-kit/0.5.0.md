# agent-context-kit 0.5.0

coding-agent-adaptation 增加 WorkBuddy、WorkBuddyDonghua、Qoder 项目目录链接，以及 OpenCode、Cursor、GeminiCLI、GitHubCopilot 通用发现层复用。Node 执行器支持显式 `--skills-dir` 和 Custom 宿主；保留已有目录、错误链接和用户内容，拒绝路径越界、上下文重叠及 Git 元数据目标。安装/更新器接受全部命名宿主，自定义路径通过 Node 入口处理。

更新能力包后按 docs/coding-agent-adaptation.md 显式选择宿主即可；已有链接无需重建，不自动分发到用户目录或清理旧副本。Windows 文件系统测试与宿主发现分别取证，WorkBuddy 系项目加载及非 Windows 矩阵仍待验。commit 为实施基线，发布提交由 Git 历史追溯。

用户可在项目上下文配置的“技能适配目录”章节逐行填写路径，执行 skill 时由 Agent 读取并复用现有执行器补缺；提供三目录示例和可选模板提示，不增加配置解析器或自动更新副作用。
