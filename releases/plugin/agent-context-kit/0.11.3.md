# 插件操作与项目上下文收尾交接

plugin-management 在启用、禁用、恢复或迁移完成后，交接到 project-context-maintenance 定点核对项目入口与条件路由，包含状态已满足的幂等重跑。已有流程直接续接，不重复选择、补装或初始化；仅查看、预演和补装为 available 不新增可执行路由。

项目状态继续由 profile 工具维护。上下文 owner 只更新受影响的入口、项目事实与长期决定，分别报告脚本结果、路由与宿主加载证据；未完成上下文收尾时不宣称接入闭环完成。初始化参考收敛到同一操作入口与返回步骤。

已部署项目正常更新本插件及 catalog，刷新已启用索引后取得指导。已有项目入口在后续明确插件操作或授权上下文维护中定点核对，普通能力包更新不覆盖项目上下文。无新增配置、远端操作或业务资料清理。
