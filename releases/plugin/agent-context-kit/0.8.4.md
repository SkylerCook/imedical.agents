# WorkBuddyDonghua 与 WorkBuddy 共用项目 skills

依据用户的项目级 skills 实测报告，将 `WorkBuddyDonghua` 命名 adapter 的默认目录纠正为 `.workbuddy/skills`，与 `WorkBuddy` 复用同一个链接。规则、记忆和用户级目录沿各自机制。CLI 参数及显式目录覆盖能力保留；回归覆盖双向复用、新项目入口及原有自定义技能和记忆保护。

## Migration

完整更新能力包及本地根脚本，在授权维护时将旧 profile 清单中的 `.workbuddydonghua/skills` 改为 `.workbuddy/skills` 并去重，再执行 DryRun、必要时 Write、Check；旧脚本可用 `--runtime Custom --skills-dir .workbuddy/skills`。旧链接不自动清理，实体目录和自定义内容保留。步骤及 Overlay 边界见 `docs/update-agents.md` 的“WorkBuddyDonghua 项目 skills 目录纠正”。
