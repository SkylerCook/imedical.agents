# 按需启用与发现入口闭环

项目插件管理在领域配置验收后调用既有 profile 工具；按需模式由工具生成、验证发现入口并记录 enabled，恢复先启用再更新的接入路径。全量模式保持原流程，自定义入口冲突和必需依赖检查继续生效。

已部署项目正常更新本插件及根 scripts 后刷新已启用索引。成员 profile 丢失时保留历史需求及缺失状态，恢复真实记录后再清理；无新增配置或旧文件清理。
