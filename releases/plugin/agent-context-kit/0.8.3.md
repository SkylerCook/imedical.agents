# 宿主技能适配优先沿用已确认项目目录

修正 WorkBuddy 参考中将文档兼容机制当作统一目录的误导：先采用用户明确目录及目标项目已确认配置，再按形态核对来源。保留官方代码项目的支持声明和未知项确认边界，不将项目差异提升为共享默认值。

命名 adapter、CLI、安装更新行为与已有链接不变。正常更新能力包取得新指导，已部署项目仅在授权适配时定点核对；不自动迁移或删除入口。文件系统 Check、宿主发现、项目规则加载和实际调用分别取证。
