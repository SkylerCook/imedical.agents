# 医生站调用图索引插件新增服务总线绑定索引

新增第三个 skill `imedicalxc-doctor-codegraph-aggregation-gen`：从只读总线库 `db_hsb.sm_hsb` 导出接入系统、注册服务、发布服务、消息订阅与路由证据，归一化为「HIS ↔ 外部系统」生产者/消费者绑定索引（HIS 侧挂接到 Controller 方法），并产出系统级绑定图（HTML / GraphML）、Controller 影响矩阵与请求码对照清单。配套 `scripts/agg/` 八个脚本（采集、捕获 MCP 结果、构建、查询、Controller 关联、两类导出、总线库连接配置）。

manifest 新增 `projectDirectories` 条目 `aggregation-index`，索引产物落在业务项目 `docs/agents/imedicalxc-doctor-aggregation/`，随项目版本提交、不随能力包分发。总线连接参数全部由环境变量注入（`KB_HOST` / `KB_PORT` / `KB_DATABASE` / `KB_USER` / `KB_PASSWORD`），`config.py` 显式列出导出时必须剔除的凭据列（`service_password`、`app_secret`、`access_secret`、`system_secret`、`encrypt_secret`），索引产物中不含任何密钥字段。

本次 bump 同时覆盖 0.1.0 之后未单独定版的既有改动：前端链路衔接查询与回调边、契约类型按全限定名字段嵌套反查、Controller 端点索引签名与类型、穿透取证确定化（消除同名控制器跨服务随机归属）、实现族按 `extends` 展开并记录继承链与 `@BLH`、声明族与 Mapper 取证补齐、产物目录统一迁移到 `docs/agents/`。

插件内脚本与 skill 继续继承 owner 版本 0.2.0，不声明独立版本。0.1.0 的索引产物与查询接口保持不变，无需迁移。
