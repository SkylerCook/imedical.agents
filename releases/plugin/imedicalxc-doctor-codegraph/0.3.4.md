# commit-impact 输出覆盖度 coverage，修复改名提交取证为空

`query_commit_impact.py` 逐提交输出 `coverage`，让下游把「索引未覆盖该文件类型」与「确实没有页面入口」区分开；同时修复 git diffstat 改名写法（`{old => new}`）导致整条提交无取证的问题。

## 覆盖度契约

每条提交新增 `coverage`：

```json
{
  "indexFresh": true,
  "methodsInGraph": 0,
  "skippedReasons": {"not_in_graph": 2, "type_contract": 8},
  "skippedReasonLabels": {"not_in_graph": "源码文件未生成方法节点", "type_contract": "契约类型（DTO/VO/PO，无方法体）"},
  "reverseProbeUsed": true
}
```

- `skippedReasons` 按 `classify_skip` 原因计数，`skippedReasonLabels` 给中文释义。
- `entrypoints=0` 时先读 `coverage`：`public_layer` / `not_in_graph` / `type_contract` 属索引未覆盖，不得表述为「无页面入口证据」；`frontend` / `resource` / `binary` 属调用图不适用。
- 消费方已同步：`build-eval-packs.js` 把 `coverage` 写入 `evidenceDigest.codegraph.coverage`，`validate-evals.js` 注入 `impactEvidence.coverage`，`render-report.js` 在「调用图证据」行追加「未入图：<原因> N / 已走常量反查」。

## 改名提交修复

原实现用 `path.endswith(".java")` 过滤源文件，而 git diffstat 的改名写法结尾是 `.java}`（如 `{guanXi => guangXi}/...`），整条改名文件的取证被静默跳过：既无方法命中也不进 `skippedReasons`，提交落入 `confidence=none`。

- 新增 `expand_rename_path()`，先展开为 `(old_rel, new_rel)` 再判断扩展名与 pathspec；diff 按新旧双路径取，旧侧内容读 `^\:{old_rel}`。
- 验证（2026-11-22_23-verify 13 条）：`57afcf84`（广西医保影像云包名调整）由 `none` → `partial-reverse`，`skippedReasons` = `not_in_graph 2 / type_contract 8`，常量反查补出 215 个入口；其余 12 条结果与修复前完全一致（29 方法、跳过文件 34→40 均为改名文件）。

## Migration

```
python .agents/plugins/imedicalxc-doctor-codegraph/scripts/query_commit_impact.py <raw-commits-<label>.json>
```

历史 `code-impact-<label>.json` 无 `coverage` 字段，下游按缺失处理（不写「未入图」提示）；需要覆盖度证据的期次重跑取证即可，无需重建索引。
