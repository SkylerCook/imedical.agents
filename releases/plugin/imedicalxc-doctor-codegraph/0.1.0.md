# 医生站调用图索引插件首次发布

纳入医生站调用图构建与检索能力，拆分为两个 skill：`imedicalxc-doctor-codegraph-gen` 执行六步索引流水线（Feign 接口扫描 → 工作区方法级调用图 → Maven biz jar 并发扫描 → 合并 → `impact_db.json` → `penetration_db.json`）；`imedicalxc-doctor-codegraph-search` 基于上述索引提供变更影响分析、方法调用者与被调用者、Feign 接口使用方、跨服务依赖追踪与提交级批量取证查询。

插件内脚本与 skill 统一继承 owner 版本 0.1.0，不声明独立版本。运行依赖 Python 3 与 `javatools`，索引产物写入业务项目 `docs/agents/imedicalxc-doctor-codegraph/`，不随能力包分发。

索引改为确定性生成：文件遍历、并发扫描结果、路径枚举与序列化均按稳定顺序输出，节点 `file_path` 使用工作区相对路径。同一源码与 Maven 仓库重复构建逐字节一致，索引可按版本比较。commit 为实施源仓基线。

索引目录由 manifest 的 `projectDirectories`（`id: codegraph-index`）声明为 `docs/agents/imedicalxc-doctor-codegraph`，`config.py` 直接解析该声明；索引数据跟随项目源码版本提交，不随能力包分发。
