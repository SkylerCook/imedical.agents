# 电子健康卡 Javadoc 日期取系统当前日期

编码规约 U 明确 `@since` 取生成当天的本机系统日期（`yyyy-MM-dd`），不得沿用镜像模板厂家的旧日期，并要求生成后对新厂家包执行 `grep "@since"` 自检。此前 `@since` 只是未定义来源的占位符，复制模板时会随类/方法注释被带成模板厂家的固定日期。规则 AA 的类级 `@since` 同口径。其余规约、入口和依赖不变。
