# imedicalxc-doctor-extend-engineer 1.0.4

编码规约新增 AO 条目：必填项必须有值，多值配置随机取值。

变更内容：

- `rules/elechealthcard_coding_conventions.md` 新增规约 AO：文档标注 Y（必填）的字段组装报文时必须保证非空，来源缺失立即抛 rpcException，不允许空值上送（空值常被平台以"数据签名不正确"等不直观原因拒绝）；扩展设定中"多值逗号分隔"且无对照规则的取值（如备案设备码/终端流水号），每次调用随机取一个，不固定取第一个。
- 插件 AGENTS.md、`rules/elechealthcard_index.md`、子 skill SKILL.md 及规约 frontmatter 的字母范围引用同步为 A~AO。
