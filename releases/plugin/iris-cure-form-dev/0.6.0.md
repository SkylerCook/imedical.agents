# iris-cure-form-dev 0.6.0

新增现有 CA/CR 模板改造的灰度收尾能力：单 Map 独占模板通过 `consolidate` 回归正式 RowID，多 Map 共用公共模板通过 `consolidate-shared` 统一回归；`cleanup` 仅删除完成引用切换后的零引用孤儿模板。三类操作均绑定模板、DOM/radio、缓存、Map 组成和检查快照哈希，并使用固定事务类完成验证、写入、回读和回滚编排。

新开发表单继续直接创建正式模板，不进入灰度合并或清理流程。使用新增命令前，目标工程必须单独部署并验证 `DHCDoc.Cure.AI.CureFormDeploy` 对应的 Inspect、Validate、Apply、staged、Verify 和 Rollback 方法；能力包更新不会自动修改服务端类。
