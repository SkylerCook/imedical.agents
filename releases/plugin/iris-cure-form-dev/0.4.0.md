# iris-cure-form-dev 0.4.0

新建表单增加部署前后人工交互测试门禁；存量响应式改造流程保持兼容。

## Migration

`expectedVersion=NEW` 的新建表单在生成部署计划前，必须执行 `interaction-prepare`、完成人工测试、执行 `interaction-check`，并向 `plan` 传入生成的 `--interaction-verification`。部署后继续完成绑定 package 和 operation ID 的人工验证。现有项目配置不自动改写。
