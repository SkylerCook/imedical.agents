## Migration

实写补记：修正空字符串参数映射 NULL 时的比较；经明确授权增加固定 SQL 绑定兼容层，修复上游 `%Execute` 参数遗漏。保留并加强事务内 COUNT/实际行数检查，授权样本清空/恢复通过；不开放任意 SQL、普通清空或自动改变执行方式。

新增显式 `lightweight-sql` 通道：固定参数化单模板 content 覆盖、持久 MCP 连接、备份及条件 UPDATE、回读与 60/120 秒预算；默认仍为手动/完整事务包。仅本地审计，不生成服务器 operation ID；使用后切回完整事务包须重新 Inspect 和绑定计划。固定 SQL 绑定层已通过一个明确授权的服务器清空/恢复样本，完整演练约 9.94 秒，前后哈希一致；不替代其它实例或真实 HIS 保存/打印验收。

48 项 Node 回归及从目标项目执行的 PowerShell 7 / Windows PowerShell 5.1 表单专项通过。项目集成测试禁止从框架仓库执行，产物归目标项目 `docs/work/cure-form/framework-tests/`；测试交付不再污染框架源仓。

新任务默认使用 `docs/work/cure-form/<task>/<Map>/`，私有快照/状态放同任务 private；项目配置和规则仍归 `.agents/`。调用方统一传 `--task-id`，或用 `--work-root` 指定任务根；旧显式输出路径仍可使用，不自动迁移既有证据、备份或未完成部署记录。

HISUI 预览 profile 指向允许的 vendor 根，runner/check 都验证原文件哈希。旧预览保留复制资源兼容；代码、资源或 runner 已变化时重新生成并验证，不复用旧凭证。升级能力包不上传 JS/CSS，也不自动修改服务器事务类。
