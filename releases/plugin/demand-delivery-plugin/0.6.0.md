# 主子需求共享提交与适用阶段

新验收v2将parentId、codeBinding及无代码原因纳入授权范围指纹。主需求与所有关联子项人工通过后方可交付共享代码；主需求正式提交一次，子项inherit真实已校验的仓库/hash，不制造独立提交。
