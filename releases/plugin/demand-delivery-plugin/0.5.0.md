# 验收技能调用即授权完整交付

用户明确调用 demand-acceptance 开展验收交付，即授权已确定批次的通过项提交、BOS 代码更新日志及推送；非 BOS 项目跳过日志。无需交付开关或再次选择交付范围，demand-commit 复用该批次授权。暂停限制、精确范围、执行门禁及阶段回执继续保留，仅查看技能、查询汇总或 Agent 自动加载不产生授权。

## Migration

新调用从分别确认交付动作改为调用即授权完整交付，需要暂不交付时明确说明。正常更新能力包并刷新已启用索引即可取得新契约；旧批次保留原授权范围、暂停限制和已完成回执，不自动升级未授权动作。索引协议和执行脚本不变，无配置迁移或旧文件清理；本轮不自动同步业务副本。

commit 记录本轮源仓基线，不表示此变更已提交或发布。
