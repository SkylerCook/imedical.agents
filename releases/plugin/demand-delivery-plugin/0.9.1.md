# 同步子进程 stdin 兼容修复

同步子进程明确关闭未使用的 stdin，继续捕获 stdout/stderr，保留非零退出与实仓 commit 门禁；Git EBUSY 提示检查宿主环境，不将错误码直接归因为 stdin。

覆盖交付 Git 取证、计划、BOS 日志及其共享实仓校验；BOS 同时修复计划 Node 子进程和非交互 PowerShell 配置调用。输入沿参数、文件或环境变量传递，不新增 stdin 协议。

正常更新完整能力包取得，无配置或数据迁移、旧文件清理。临时 shim 需在原宿主不预加载它验证后再退役，不自动修改本机环境或业务副本。专项加入既有三平台 Node 22/24 CI；本机证据与尚待取得的平台/宿主结果分别记录在维护日志和队列。
