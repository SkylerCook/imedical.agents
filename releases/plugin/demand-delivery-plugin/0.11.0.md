# 标版提交格式校验

Git 2.54 及以上可在明确选择的标版业务仓启用本地提交消息检查，并继续执行现有钩子。框架推送新标版提交前核验实际提交对象的完整消息和需求号。

已有工程通过正常更新取得。仓库级钩子由使用者显式启停。旧批次保留原回执，已推送的历史提交可继续补记回执和办理 BOS 补录。
