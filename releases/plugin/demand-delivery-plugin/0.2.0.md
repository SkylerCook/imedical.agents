# 连续人工验收与逐号交付

新增 demand-acceptance 技能：持续接收人工结论，复用既有提交/BOS 能力，按目标仓库串行发布，恢复部分交付，报告整理不阻塞交付。人工通过和完整交付独立汇总，固定 BOS 多需求号的单行半角逗号格式。

按需批次索引辅助脚本校验占有、范围、授权记录和精确提交回执，不执行远端操作、不替代正式 run。无新依赖与配置迁移；现有单次 demand-commit 保持独立。选用 BOS 阶段才使用已接入的 bos-plugin。

通过正常能力包更新并刷新 thin-index 发现新技能；本次源仓实现不表示业务副本已更新。隔离测试和独立演练结果见维护日志，真实宿主/BOS 与三平台 CI 实跑分别取证。
