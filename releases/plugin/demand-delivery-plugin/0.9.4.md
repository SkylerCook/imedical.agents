# 核对 `--pass` 交付范围并接续执行

`--pass` 登记验收通过后立即逐号交付。裸参数有多个候选时，在一次澄清中确认验收和交付的共同范围。宿主需要审批时，各阶段传递用户原话与实际目标，分别申请本地提交、推送和适用的标版 BOS 写入。被拒绝时保留验收与成功回执，沿宿主允许的途径从受阻阶段恢复。

已有工程正常更新能力包并刷新已启用索引。旧批次保留原范围、暂停限制和回执，沿原接口续接。
