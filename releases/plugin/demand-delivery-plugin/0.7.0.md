# 人工验收通过快捷参数

`demand-acceptance --pass` 复用现有人工结论与交付流程，支持逗号编号列表及换行粘贴“需求号＋标题”；裸参数只定位唯一待验收需求。推荐保留标题，先按编号定位再复核标题，冲突或无法确认时暂停该条；逐号核对范围、来源和冲突，保留原话与已完成回执，显式暂停及主子交付门禁继续有效。帮助或讨论示例不触发业务动作。

这是 Agent 层参数，不增加脚本 CLI、状态机或批次 schema。已有工程正常更新能力包并刷新已启用索引，无配置迁移或旧文件清理。真实宿主发现和行为验证沿既有 P2 验收队列取得；commit 为本轮实施基线。
