# project 暂无需求号提交

新增显式布尔参数 `--no-id`，可与 demand-commit 的 `--plan` 或 `--commit` 组合，仅允许 project，且与脚本 `--demand` 互斥。无编号提交省略标题中的需求号括号，保留方案型修改说明；执行模式、授权、精确文件、计划完整性、漂移、pull、hook 和提交验证沿原流程。普通调用及 standard 继续要求数字需求号。

无编号 v1 计划记录 noId=true、demand=null，默认路径采用独立随机标识；上游前进后复核、重新计划时沿用无编号状态。已有数字编号 v1 计划仍可恢复，不自动 amend 历史、创建验收批次或写 BOS。

正常更新完整能力包并刷新已启用索引取得功能，无配置迁移或旧文件清理；本轮不自动部署业务副本。跨平台与真实宿主结果分别核验。commit 记录实施基点。
