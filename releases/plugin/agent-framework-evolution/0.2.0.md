# 明确授权的隔离待审补丁模式

默认只读审查保持。当前任务/项目明确授权且完成准入、去重、源仓身份与隔离范围核对时，合格候选可在源仓形成待审 diff，无需逐项重复询问。源仓不可用或证据不足仅交候选，维护不递归反馈；普通自动加载不授权写入。

沿既有能力包更新分发；本次只形成源仓隔离 worktree 待审差异，不更新业务工程、不提交或发布。已有项目授权上下文维护时才合并模板或授权约定；普通更新不重写项目 AGENTS/profile。无新连接配置、生产样式、浏览器运行器或旧文件清理。验证和限制见 [维护记录](../../../maintenance/validation/ui-framework-optimization-2026-10-23.md)。commit 为实施基线。
