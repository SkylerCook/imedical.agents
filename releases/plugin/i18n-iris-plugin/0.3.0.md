# 按项目授权接入 i18n 产物目录

manifest 声明 XML 打印模板、原文、术语表及 CSP 同步恢复目录；目录治理启用后通过共享解析器选择 docs/delivery 默认值，未接入工程保留 legacy 路径。本次显式参数和有效项目 profile 始终优先，XML 同步与翻译复用相同 outputDir，单模板或对象可显式细分目录。

新增只读 i18n 目录解析入口，XML PowerShell 同步调用该入口；术语提取、字典 SQL、XML 翻译和 CSP 备份流程读取相同目录决策。页面翻译 seed 保留 backend SourceRoot，初始化及更新不覆盖源码。业务恢复副本与框架目录迁移的批次回退备份分别管理。

首次接入、预建目录和已有文件归类均需目标工程明确授权；仅更新插件不启用治理、不迁移文件、不部署业务系统。旧任务沿用已记录的原文、译文、备份及 manifest。commit 为本次实施前源仓基线。
