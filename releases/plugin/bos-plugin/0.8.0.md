# 显式夜跑技能入口

bos-demand-handle 支持 `--night`，与自然语言夜跑共用既有批次 workflow。Agent 从当前上下文及工程配置准备批次和编排资料，用户无需手填 JSON；普通单需求路径保持兼容。

新批次显式引用决策策略与已有工作区预检计划；Codex 使用真实宿主额度快照进行派发门禁，其它宿主显式关闭 Codex 额度策略。复用现有 Overlay 和阶段调用，旧批次不静默迁移。

参数只选择流程，不新增外部操作授权，不自动启用插件、创建多会话或启动后台服务。已有工程更新能力包并刷新已启用技能索引后取得入口，无私有配置迁移或旧文件清理。本记录描述本地变更，不表示已提交、发布或同步业务工程。
