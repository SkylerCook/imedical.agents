# 工作记录来源、显式拆合审查与组合导出

bos-demand-entry 增加 Agent 层 --split 开关，与 --excel 独立组合；省略模式时进入 --text。展示业务价值、范围、独立验收点、代码归属、依赖及拆合理由，允许保留一条。未传开关的默认业务目的拆分不变。

显式 --work 从工作记录生成 v3 草稿，使用工作目标/内容及可选预期成果或工作结果，保留实际进度；无需 Git 取证或提交依赖，回填编号不改来源，提交路径明确阻断。代码来源保持默认和 v2 兼容，不混合来源，不伪造取证。复用 prepare/render/Excel/bind CLI 与渲染，工作来源跳过 collect。共享文件无法隔离时只交候选文本，该批草稿/Excel 受阻；不重复分配取证或自动修改历史。工作量通过实际成果与证据表达，不虚构条数或工时。

普通更新能力包并刷新已启用薄索引即可取得参数描述和正文，无配置迁移或旧文件清理。场景清单用于真实 Agent 后续验收，静态检查不证明模型执行效果。commit 为源仓基线。
