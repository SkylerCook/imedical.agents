# BOS 配置凭证获取指引

个人配置初始化返回待填字段对应的获取来源和后续步骤，需求查询及代码更新日志缺配置报错附字段处理办法。配置说明区分统一 access_key、个人需求查询凭证和日志接口 Key，沿统一连接指南明确 cuser 使用实际识别的完整账号／工号、所在组、实际关联研发项目及可省略的默认超时。

复用现有 bos-init 与仓外共享私有配置，真实凭据不内置。只使用一项时另一段可暂不填写；正常更新能力包取得提示，无配置迁移或旧文件清理，已有字段值保持。源仓更新不自动修改业务副本或宿主 MCP。「我的 Key」与日志凭证的具体对应关系仍待实际页面核实。

commit 为本轮实施基线，发布提交由后续 Git 历史追溯。
