# 个人开发待办与工作量查询

新增 skill/CLI `--todo [日期或范围]` 和 `--workload 日期或范围`，以及等价 JSON/MCP todo/workload 模式。待办可不带日期，带日期按预计完成时间；工作量必须给执行日期。单日及起止范围包含截止当天，通过向上游取至次日再本地校验原日期字段实现。

接受人确定开发归属，当前人结合状态区分本人待办、返工与已流转他人的工作；已完成但当前人仍为本人的需求计工作量，取消/已拆分/回置排除，未知组合单列待核对。输出口径、状态计数及排除原因。仅复用原只读查询接口，不保存私有结果。

查询展示默认列表，需求号与完整标题为必需列，个人两模式分别补充预计完成时间或执行时间及状态，各类默认列表末尾为发起人、发起组；用户可指定其它列，或只要单行逗号分隔的纯需求号串。输出格式归 skill 展示契约，不改变 CLI/MCP、查询条件或统计口径；待核对项与正式结果分开。

旧 pending/project-pending/list/history、按编号和字段说明接口保持原语义。正常更新能力包并刷新已启用索引即可，无配置迁移、旧文件清理或自动业务副本更新。commit 为实施基线；源码与合成测试不等于所有宿主或上游完整性已验证。
