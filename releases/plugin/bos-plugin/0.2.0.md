# BOS 组织分发与个人初始化

增加 Windows LOCALAPPDATA 私有配置、init-config 自动生成与用户环境绑定、公司无凭据默认地址更新及 TODO 查询门禁，完整旧私有连接保持优先且失败不回退。合并 pending/project-pending/history、日期默认、排序与计数。框架为唯一维护源，用户级技能引用插件，个人配置独立于项目更新。

## Migration

已有完整配置继续显式指定 BOS_MCP_CONFIG。旧本机隐式配置用户先设置该变量，再切换到框架入口；新使用者按插件 usage 初始化。客户端切换与业务工程启用分别按授权执行。

commit 为实施基线，发布提交由后续 Git 历史追溯。

显式 migrate-config 保留原文件并迁移身份/凭据到标准目录，目标存在时停止覆盖。非 Windows 自动初始化明确停止，原显式配置查询继续支持。

初始化检查目标及已存在祖先的物理路径，拒绝 Windows 应用包 AC / LocalCache 重定向，保留正常自定义 Junction 支持；环境变量回读不作为桌面可访问的证明。
