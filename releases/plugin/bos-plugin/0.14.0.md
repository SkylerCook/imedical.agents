# 项目与产品非项目来源查询

新增互斥来源入口 --proj / --dev，未选模式时默认个人开发待办，可与 --todo 日期或 --workload 必填日期组合；日期及人员/状态口径保持。项目限定 source 为项目，产品按所有非空非项目来源理解，不只精确来源产品；非项目复用原查询接口并在本地排除项目，缺失来源进入待核对清单。JSON/MCP 提供本地 sourceScope，并在口径及计数中说明来源筛选。

正常更新能力包并刷新已启用索引取得，无私有配置迁移、旧文件清理或自动业务部署。原 query JSON 的 list 默认值和脚本无参数 serve 保持；skill 无参数以 --todo 调用。以前一已提交 BOS 0.13.1 为版本比较基线，本发布仅包含来源查询相关改动；不调整夜跑流程及客户端运行行为。
