# BOS 日志补录与按技能分段的共享配置

新增 bos-code-update-log：读取已存在的 Git 提交，生成离线计划，按明确授权写入 BOS；跨仓聚合保留全部不同菜单和修改说明。查询与日志统一读取 BOS_MCP_CONFIG 指向的仓外共享文件，各自读取与 skill 同名的段，凭据独立。

## Migration

运行时只接受新结构，移除旧平铺/mcpServers 包装、仅身份文件及连接环境变量回退。已有平铺查询配置通过明确执行新版查询脚本 migrate-config <原文件绝对路径> 原地转换，保留查询值，日志段加入 TODO；未识别的包装或字段须人工核对。普通项目更新不迁移私有配置，不改客户端或用户级入口。

项目主动使用既有更新器，enabled 生成四个日常技能索引，available/disabled 保持原状态。个人初始化只绑定共享文件路径，不设置旧连接变量；凭据独立填写，日志缺失只阻塞日志。旧工程须主动更新才能读取新配置。详见插件 usage、code-update-log 及 docs/update-agents.md。

本记录的 commit 为本轮源仓基线，不表示变更已提交或发布。真实网络操作与非 Windows/Node 22 验证独立取证，不将合成测试视为服务端验收。
