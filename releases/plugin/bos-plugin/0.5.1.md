# BOS 查询参数说明

bos-demand-query 将额外筛选、默认值核对和参数报错路由到现有 usage 的查询参数契约。完整表区分上游 18 项必填字符串及可选 body、本地已开放字段与未开放字段，并说明 explain 固定值、个人身份要求、日期默认值和本地模式/排序。
