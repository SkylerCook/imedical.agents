# bos-plugin 0.1.0

首次提供独立 BOS 接入、只读查询与跨技术栈需求处理。复用通用 workflow、领域规则、交付和提交门禁，不新建调度器或状态机。显式配置与代码位置解耦；默认 available，bos-init 不生成日常索引。

原用户级技能维持原状。后续迁移须显式配置 BOS_MCP_CONFIG 或连接环境变量，再切换入口并验证。平台与宿主覆盖以实际测试证据为准。
