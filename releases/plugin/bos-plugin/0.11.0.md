# 按主题和资料向其他组提需

bos-demand-entry 支持主题及可选资料、接收组的自然语言输入，不要求 Git；新 v3 source=request 复用 bug/change 三段式、prepare/render/deliver/bind 和 Excel，接收组保留为交接元数据，不自动映射产品组或指派人。产品标识未知的主题需求可先按事实命名；主题提需和工作记录均无代码提交对象，禁止混入取证/提交字段。

包含本轮尚未提交的完成备注规则：结合上下文、代码及验证判断完成状态，已完成条目通过 remarks 在末尾增加【备注】已完成，保留原有备注；待解决问题不因文本写完而标记完成。

沿用原 CLI 和输出保护，旧代码 v2、工作 v3 草稿保持兼容；旧脚本不支持新 request 草稿，使用新来源前完整更新能力包并刷新已启用索引。无个人配置迁移或旧文件清理，不自动发送、写 BOSS、提交 Git 或同步业务副本。commit 指本次实施源仓基线。
