# 按产品交付目标区分 IRIS 标版需求标签

`bos-demand-entry` 的三类来源共用逐条名称规则：修改 IRIS 标版产品代码、产品配置或 UI 时生成 `{IRIS}[标版] 标题`；会议、演示、造数据及临时环境准备沿非标版工作命名。计划与已完成开发适用同一判定，不根据来源或 Git 文件类型自动打标签。规则事实源见 [skill](../../../plugins/bos-plugin/skills/bos-demand-entry/SKILL.md#需求名称与标版标签各类来源共用)。

脚本兼容紧接产品标识的可选 `[标版]`，旧名称继续可读。默认 title 仅去除产品标识并保留标签，显式 title 与回填的 BOS 最终标题保持原文；文本和 Excel 共用名称，不自动修改“加入标准版”等分类字段。既有 CLI、v2/v3/v4 草稿协议和提交依赖不变，其它产品沿项目约定。commit 记录实施基点。

## 更新与兼容

正常更新能力包并刷新已启用索引取得；全局适配入口继续解析原技能，无需修改入口副本。旧草稿及历史 BOS 名称不自动补标签，无私有配置迁移或旧文件清理；源仓实施不自动更新业务副本、提交或操作真实 BOS。
