# 待办创建日期默认排序及日期排序入口

新增个人 CLI/skill --sort 和 --order，支持创建、预计完成、分配、执行和操作日期升降序，JSON/MCP 沿用 sort/order。所有来源的个人待办默认改为创建日期升序，同日需求号升序；缺失或无效日期置后。待办、工作量及通用默认列表均展示创建时间，并保留发起人/发起组；自定义列和纯编号串保持原约定。

## Migration

此前 todo 未给排序参数时按预计完成时间升序。需要保持旧顺序的调用显式指定 sort: "预计完成时间", order: "asc"，或 CLI/skill 追加 --sort 预计完成时间 --order asc。日期筛选、归属分类、条数及返回结构不变，工作量仍默认执行时间升序。

正常更新能力包并刷新已启用索引取得，无私有配置或数据迁移、旧文件清理，不自动更新业务副本。
