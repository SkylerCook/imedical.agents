# BOS 个人配置兼容 JSONC

查询和日志沿原 `BOS_MCP_CONFIG` 路径读取严格 JSON 与带注释的 JSONC，个人初始化补段和显式平铺迁移保留原注释与值。插件的固定解析依赖随完整目录分发，独立查询副本可离线读配置。更新已有个人文件时保留其访问权限。

查询、日志与工作台复用原地址校验。工作台按现有连接方式展示来源，支持对已有自定义 HTTPS 地址做脱敏替换。

旧配置可直接使用，普通更新无需修改个人文件。需要与旧版消费者共享时继续使用严格 JSON。已经使用注释且要切回旧版的工程，可先用新版迁移入口显式恢复严格 JSON，再运行目标旧版 `defaults` 核对。
