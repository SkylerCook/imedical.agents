# 统一技能帮助入口

为本插件自有 skill 增加统一帮助协议的前置路由。`--help` 或查看用法先读取当前能力定义并展示帮助，附带执行参数也不进入业务流程；帮助优先于启用、连接检查和业务前置，不自动启用插件。

这是 Agent 层帮助约定，不改变脚本 CLI、索引模板、vendor 内容或业务配置。源路由随正常能力包更新分发，已有 thin-index 继续指向 source；Overlay 从共享 CapabilityRoot 取得协议。无配置迁移或旧文件清理，源仓结果不代表下游已更新。commit 为本轮实施基线。
