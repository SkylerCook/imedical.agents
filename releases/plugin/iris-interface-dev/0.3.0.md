# 接口流程复用文档目录契约

接口文档解析复用 extract-doc 的目录声明，不维护重复路径；字段诊断使用实际解析产物，实施计划默认与当前 `parsed.json` 同目录。新 profile 模板使用 `outputRoot: auto`，由解析器决定默认根；已有显式目录和 `docs/interface` 配置保持优先，不自动改写。

extract-doc 依赖范围更新为 `[0.3.0, 0.4.0)`，提供可选治理默认值和旧路径兼容。更新不启用项目治理、不搬移历史文件或改变业务操作授权；接口 schema 与编码/部署分工保持不变。
