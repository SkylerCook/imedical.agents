# 明确业务共性与主题差异的判断边界

区分公司规范推广的来源证据与当前业务实现的适用范围：单一风格材料可用于业务共性适配，不能自动将实现限定于该主题。开发与评审按对象语义和责任层判断，区分操作采用图标与主题图标资源，保留有依据的风格差异。commit 为实施源仓基线。

沿正常框架更新取得；无配置迁移、业务 CSS 发布、第二套组件库或旧文件清理。源仓规则和场景试读不代表业务副本已经更新或正式 UI 验收通过。
