# 公司 UI 规范与评审初版

以 IHOS 海蓝、PURE 天蓝为两个评审基准，将30个画板与说明书提炼为共性规则、按需场景参考、风格差异和可追溯证据。提供规范/开发核对及截图/浏览器评审两个日常入口，纯init沿既有流程接入。通用层不要求IRIS profile、不提供生产CSS或第二组件库；后续技术栈适配直接依赖此层。

vendor仅保存PDF、标注数据与整板原图的证据子集及摘要，保留公司版权与分发条件；不含查看器运行时、其它主题或业务私有事实。通过正常更新取得后仍默认available，按项目启用集合接入；无自动启用、业务改造或远端发布。commit为实施源仓基线。
