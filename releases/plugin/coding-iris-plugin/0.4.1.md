# coding-iris-plugin 0.4.1

前端源码、上传内容和服务器运行编码统一使用 canonical `utf8`。前端编码 v3 迁移会在实际字节通过 UTF-8 门禁后，将旧 `project-utf8` / `standard-gb2312` profile 规范化为 `utf8`；真实 GB2312、mixed、UTF-16 或 unknown 文件保持阻塞，不自动转码业务源码。

`project-utf8` 和 `standard-gb2312` 继续兼容读取，后者只服务用户明确指定的历史工程。当前导出和部署默认直接使用 UTF-8 源文件，旧 GB2312 转换与 promote 工具保留为显式 legacy 路径。

## Migration

已部署业务工程先更新 `.agents` 能力包，再对 enabled `coding-iris-plugin` 运行更新器 DryRun 和 Write，使 frontend encoding v3 钩子规范化 `.agents/config/iris_project_profile.md`。检测到真实 GB2312、mixed、UTF-16 或 unknown 时必须停止并人工处理；迁移器不会自动批量转码业务源码。
