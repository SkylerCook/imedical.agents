# coding-iris-plugin 0.8.0

同一未发布版本补齐 `compile-csp.js`：CSP 上传后通过官方 Atelier action/compile 一次批量编译明确目标，默认本地计划、显式执行、检查顶层/逐文档错误并报告耗时，不自动重试或扩展父页面。部署 skill、规则和模板同步移除旧任意执行编译指引；无需额外依赖。

纳入框架自维护 SFTP vendor 运行时，固定依赖和哈希锁；修复路径边界、忽略规则、原子替换、内容校验、错误/超时及主机密钥信任。保留五个工具名，新项目默认禁用。

## Migration

旧项目不自动替换外部工具。完成依赖和可信主机密钥准备后，显式设置 sftp.runtime=vendor，通过 sftp-vendor-v1 迁移单个启动参数。新运行时拒绝越界、未知主机和非原子覆盖，SSH 命令默认禁用；详见 vendor/sftp-server/README.md。

本记录 commit 为实施基线，尚未提交发布。

同一待发布 0.8.0 增加 `deploy-frontend.js` 统一前端部署入口及 vendor `upload-batch.py`，固化上传、回读和 Atelier 编译，默认本地计划、显式执行，不生成临时脚本。用法见 `plugins/coding-iris-plugin/scripts/iris-tools/README.md`；源仓变化不代表业务项目副本已更新。
