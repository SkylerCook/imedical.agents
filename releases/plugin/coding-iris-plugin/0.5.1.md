# coding-iris-plugin 0.5.1

新增 `iris-demand-promote`，用于把已提交的 DEV 需求补丁安全移植到独立 PRD 按需导出仓库：先刷新 PRD 服务器基线，再按需求提交边界三方应用补丁，默认只创建本地 PRD 提交，不执行上传、编译或生产部署。

`export.js` 同步增加 CSS、只读 probe、JSON 输出和临时 staging 导出能力。

该版本号已随 `ea5b246` 进入共享 `origin/master`；本记录补齐既有发布事实，不通过改写共享历史回退版本号。后续修复从现存 `0.5.1` 连续发布为 `0.5.2`。
