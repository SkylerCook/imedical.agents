# 修正 Parameter 命名并补齐复用与继承审查

CLS 规范以 ObjectScript 语言合法性为先，新增 Parameter 默认 UpperCamelCase，保留合法全大写及既有契约。编码与 Review 共用清单补查公共方法提取后仍重复的业务规则，以及重复稳定业务标识的维护必要性和归属；不要求所有重复都抽象、所有字符串都常量化。

新建类在后端编码流程核对项目 profile、同职责类及公共基类，模板标明 Extends 需要适配，Review 要求继承依据。医生站组注册类的指定公共基类要求放在 doctor-dev 领域默认配置中；通用规范不硬编码业务类，也不要求所有项目统一继承。已确认医生站类型的旧项目在建类和 Review 时也读取最新领域约定；旧 profile 无须靠自动覆盖取得规则，有显式冲突先澄清。分发与验收步骤见 docs/update-agents.md。

既有 check-cls-format.js 复用 cls-format.js 的词法边界检查声明与直接引用；非法未限定 ASCII 声明给出提示，拼接歧义、限定/非 ASCII 名称和动态引用交人工核对。字符串/注释不作为代码，复杂结构保守降级。仍为只读 advisory，不改文件、不增加提交门禁、不替代 IRIS 编译。

通过正常能力包更新取得，无配置迁移或旧文件清理，不自动重命名业务代码。新增本地回归及既有三平台 Node 22/24 CI 入口；非本机 CI 和真实 IRIS 编译另行取证。起因是单任务漏检反馈，不作为普遍发生率证据。commit 为源仓基线，不表示本轮已提交。
