# coding-iris-plugin 0.7.1

`iris-demand-commit` 新增显式 `$iris-demand-commit --plan|--commit` 调用契约并兼容单横线别名：`--plan` 只生成提交计划和完整 commit message，不执行 pull/commit 或继续追问；`--commit` 视为本地提交明确授权并直接完成 plan/apply/verify。自然语言路由、`standard/project` 判定、精确文件保护、pull 后重新确认及独立 push 授权保持兼容。
