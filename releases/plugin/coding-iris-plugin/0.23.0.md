# 内网独立导出与完整 XML 离线修改

独立 Windows PowerShell 5.1 脚本按 UTF-8 TXT 或版本 XML 范围采集当前实际源码，支持指定目录、最小批次和摘要恢复；聚合 XML（含 Project 元数据）可离线按对象编辑，默认只交付修改对象的 changes.xml、对应 rollback.xml、实际变更说明和摘要 manifest；Verify 独立核对，原包、完整类属性和未修改二进制受保护。无 Node.js、MCP 或外网依赖，不自动导入、编译或提交，不改变受管 source-sync 和公共资源契约。

普通能力包更新只分发 XML 离线编辑 helper 与路由；人工源码导出独立归源仓 tools/iris-code-export/，提供无需框架的 ZIP，不随 .agents 分发。无配置迁移与旧文件清理。
