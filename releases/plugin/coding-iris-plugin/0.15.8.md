# coding-iris-plugin 0.15.8

修复前端部署重复连接及校验后移：direct 批处理与 guarded 持续会话共用传输实现，一次执行一个 Python 进程和一条 SFTP 连接。临时文件上传完成后再次检查目标摘要，原子替换后立即校验最终目标；首个失败阻止后续写入。guarded 复用最终摘要证据，保留 Git 基线、合并、逐文件状态持久化及编译后源检查。
