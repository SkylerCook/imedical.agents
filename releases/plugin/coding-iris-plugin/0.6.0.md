# coding-iris-plugin 0.6.0

新增 `iris-demand-commit` 标版/项目需求提交能力：按需求文件解析 GitRoot，生成说明具体修改方案的仓库级提交信息，并在用户明确授权后执行安全 pull 门禁、精确路径提交和结果验证。标版采用三行消息并强制 upstream，项目采用两行消息且兼容纯本地仓库；任何 push、部署或远程编译仍需独立授权。

新增 `demand-delivery-type-v1` 配置迁移。已部署工程更新时从明确项目上下文填充 `standard` 或 `project`；证据不足或冲突时写入 `TODO` 并要求用户补全，不按目录、`contextMode` 或 Git remote 猜测。
