# coding-iris-plugin 0.12.0

新增 iris-demand-entry：仅 standard，从精确工作区改动或指定历史提交的实际补丁提炼需求，默认输出可复制文本，支持可选 --excel/--Excel 生成 BOSS 29 列导入表。草稿保存代码来源、每仓库修改说明和验证信息；用户录入 BOSS 后绑定需求号及最终标题，复用 iris-demand-commit 消息与 plan/apply/verify 流程。

用户入口提供 --text、--bind、--plan、--commit、--help 模式；--excel/--Excel 为可选开关，--rev 指定历史提交，--same-title 显式沿用草稿标题。底层脚本接口保持不变。工作区漂移阻止沿用旧说明；历史提交仅生成消息，不自动改写历史或创建空提交。文本与 Excel 共用内容，已导入条目排除，Excel 校验必填列/枚举/日期，指派人不水平居中。只依赖 Node 内置模块，不增加 Python/npm 部署依赖。

现有 project 和 --plan/--commit 接口保持兼容。已部署工程更新能力包后重建 enabled 插件 thin-index；无配置迁移、旧入口删除或自动副本同步。六个依赖插件的范围同步兼容至 <0.13.0。验证状态见维护日志；BOSS 实际导入及非 Windows 矩阵不以静态测试代替。

commit 字段记录实施基线；实际发布提交由 Git 历史追溯。
