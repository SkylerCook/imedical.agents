# ObjectScript 官方简写与小写约定

新增 ObjectScript 命令、内建函数及特殊变量优先使用 IRIS 官方简写并统一小写，块式控制流沿用小写全拼。事务命令写作 ts、tro、tc，保留后条件和回滚层级。离线表列出命令与常用内建函数、特殊变量的统一写法；halt 和 hang 分别使用全拼。
