# 部署上下文、诊断与会话阻断范围修复

- direct SFTP 批量部署向 CSP 编译传入工作区和需求类型，沿受管会话执行。
- 受管单会话的 pending 策略仅对显式声明文档的恢复 GET 开放；保留 token、死 owner、目标、退出及未知写核实约束，恢复入口仍不允许写入；普通操作按实际冲突范围准入。
- 部署回执保留安全错误码和 beforeSend；CSP 清理失败不再覆盖原始请求错误。
- 已部署工程同步 owner 和根 scripts 后执行现有 Check；不更改私有配置、资格、会话或历史恢复材料。

工具诊断补齐：正常测试断言失败继续返回原结果；JSON-RPC 无效参数/方法及明确 namespace 不存在的拒绝不触发未知写阻断。其它未知执行错误继续阻断，并经 IPC、原生 MCP 和 CLI --json 向原调用方保留工具响应与错误码；响应正文不写会话协调文件。共享实例仍串行执行，普通失败与仅注销未确认不再永久封锁全池；未知写按目标范围隔离，影响不明的脚本保留 namespace 写保护，只读诊断与无冲突操作继续。
