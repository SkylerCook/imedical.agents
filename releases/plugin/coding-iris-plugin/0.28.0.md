# 前端源码与服务器编码分离

按需项目首次确认服务器编码，修改前和部署入口执行硬校验。保留本地 UTF-8，上传按配置无损生成 UTF-8、GB2312、GBK 或 GB18030 产物。Atelier 前端改为二进制上传和回读，覆盖 CSP 编译、source-sync 及移植发布。更新器保留显式编码配置，导出回执区分本地输出与服务器目标。

## Migration

同步 coding 插件、共享 scripts/lib 与 vendor/frontend-encoding。按需项目首次运行 frontend-encoding-cli confirm 保存开发人员已确认的编码和目标指纹，随后复用配置。旧 standard-gb2312 保留 CP936／GBK 的历史含义。已有源码保持原样，旧发布计划重新同步、生成及复审。

既有缺省前端通道保持 SFTP，新项目可显式选择 Atelier，已有显式 SFTP 配置保留。GB 系列目标使用 Atelier binary/enc，无法保证目标编码时停止相关上传；既有已确认 UTF-8 的文本通道保持可用。真实服务器与跨平台验收状态见维护日志及治理队列。
