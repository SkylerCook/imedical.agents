# 受管 CLI 与原生 MCP 统一会话

新增同机用户级会话管理、排队、空闲注销及未知结果恢复。普通单会话查询允许资格 pending；显式禁用、批量资格与写入门禁继续生效。通过迁移配置和实际回执核对 Agent 路径，保留 vendor 业务工具实现并补丁禁用自动重试。

## Migration

沿现有更新器 DryRun → Write → Check；识别的 vendor 配置转为受管 Node 适配入口，自定义配置返回待适配原因。保留 env、disabled、其它服务及旧恢复材料。更新后重启受影响 MCP 并以真实调用回执验证；Overlay 先 CapabilityRoot 再逐 ContextRoot。定向回退先结束自有会话，只恢复未被用户改动的迁移字段；回退后失去统一管理保障。详见 docs/guides/iris-managed-sessions.md。
