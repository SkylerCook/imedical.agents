# coding-iris-plugin 0.5.2

修复 `iris-demand-promote` 的计划隔离与冲突续跑门禁：同名 DEV/PRD 仓库按绝对路径身份生成独立临时计划目录；`continue` 重新校验 DEV/PRD HEAD，并拒绝未暂存或未跟踪的计划外状态。

专项测试为 CLI 子进程增加超时与错误收敛，避免回归进程无限挂起。
