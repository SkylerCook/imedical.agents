# coding-iris-plugin 0.4.2

frontend encoding v3 迁移器现在可从 workspace-overlay manifest 明确识别 backend-only：至少声明一个 `backend` SourceRoot 且没有 `frontend` SourceRoot 时，将旧 profile 规范化为 `N/A (backend-only)`，不再遗留旧 `TODO` 双模式提示，也不扫描父目录或 sibling。

无法从 SourceRoot 声明证明 backend-only 的场景继续阻断；前端导出入口识别 N/A 后也会明确停止，不写 source 或 staging。若后续新增 `frontend` SourceRoot，迁移器会在实际文件通过 UTF-8 字节门禁后将 N/A 规范化为 `utf8`。

## Migration

已部署 backend-only Overlay 更新能力包后，重新运行 `update-agents.ps1` 的 DryRun 和 Write；确认输出从 `config-migration-planned` 收敛为 `config-migration-applied` 或 `config-migration-unchanged`，并检查 profile 为 `N/A (backend-only)`。本迁移不修改业务源码。
