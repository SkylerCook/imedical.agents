# coding-iris-plugin 0.15.0

日常开发部署默认使用 direct：明确目标、文件和授权后按本地文件上传，不要求需求号、Git 基线会话、fetch/pull 或三方合并。保留整批预检、Storage 保护、上传前并发变化检查、条件上传、回读及编译诊断；失败不自动重试或回滚。

需要基线合并时使用 `--mode guarded --demand <id>`；仅带 `--demand` 的旧命令继续使用 guarded。两种模式都不修改源码或暂存区，配置及历史会话无须迁移。业务工程需按现有更新流程同步能力包后生效，源仓变更不代表副本已安装。commit 为实施基线，发布提交由 Git 历史追溯。
