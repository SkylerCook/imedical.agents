# 部署失败有限恢复与授权沿用

direct/guarded 逐文件读取及确证未发出的上传共享最多两次额外尝试；第二次仍失败立即停止本次部署并汇报，不通过重跑命令或新建批次重置额度。每次恢复保留本地字节、远端快照、原通道、冻结发布和夜跑准入检查，回执记录 recovery；部分上传与编译后读取只继续当前步骤，不整批重放。

guarded 明确编译失败返回 compile-failed 并保留上传快照，不再生成未知结果 resume 问题。原任务包含修复时先诊断再经原入口执行，范围变化或真实人工决策才提问；未知写入/编译、旧 unknown 会话、公共熔断及 Storage 保护保持原契约。

正常完整能力包更新取得，无配置迁移或旧文件清理。SFTP 批量 worker 证据不足时继续停止，不重启或切换通道；真实项目、资源及非本机矩阵结果仍分别取证。本次不改写 0.22.0 的不可变发布记录。
