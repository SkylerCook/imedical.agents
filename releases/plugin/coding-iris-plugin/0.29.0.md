# 会话诊断与自动恢复证据

准入与受管池共用 warning 时效判断，状态增加 blockingReasons、nextAction 和观测能力说明。失败保留发送阶段、底层安全错误码及实际 HTTP 状态，注销 Cookie 变化独立归因。现有恢复入口可自动采用同代本地关闭回执，未知写仍须明确核实结果，恢复历史先落盘。

前端 confirm 可通过 --files 在配置写入前验证本地源码对目标编码的可表示性。旧调用兼容并返回选择指引。

已有项目通过正常更新同时取得共享 scripts 与 coding 插件，结束旧受管会话并重启 MCP。旧配置无需补字段，风险与恢复历史保留。支持与试点范围见 maintenance/validation/iris-session-governance-2026-11-13.md。
