# 独立开发方式与离线源码交付闭环

以 ContextRoot/config/iris-development.json 的 developmentMode 独立选择 connected/offline，复用编码、Review 和交付；受管医院远端入口提前阻断，显式模式参与在线计划漂移检查，旧配置缺省与旧计划保持兼容。源码助手自已提交的独立工具基线 adf249084724199e7837895020c3c32eed751dff 迁入插件唯一实现，支持人工目录、冻结任务范围和实际 SourceRoot/GitRoot 绑定；XML 可编辑对象进入源码 Git，原包与恢复基线私有分离。独立 ZIP 取同一脚本，旧参数和 v1 记录严格读取。

完整更新共享能力包并刷新 ContextRoot 后，在授权维护中明确开发方式；普通更新不改业务配置、任务或连接。既有文字离线约定须显式补齐配置。原生 MCP/外部 IDE 由 Agent 规则约束。新增/删除/重命名暂不支持，本地 Verify 不证明医院导入、编译或验收。非 Windows 打包明确停止，未迁移旧恢复材料。
