# 开发入口接入共享复用流程

三个 IRIS 编码入口在新增、替换或复制实现前查找候选并核对契约，最终 diff 后复核重复实现与消费者兼容性。通用角色和 workflow 共享同一流程，支持离线与单 Agent 串行执行。

已有项目通过正常更新同时取得 agents/、workflows/ 和 coding-iris-plugin；Overlay 更新共享 CapabilityRoot 后沿现有流程刷新 ContextRoot。配置迁移和旧文件清理均无需执行。
