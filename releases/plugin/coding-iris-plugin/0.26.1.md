# 会话身份未知时停止自动恢复

部署恢复明确拒绝 `sessionUncertain`，避免首次认证响应丢失后再开会话。已持有有效 Cookie 的瞬时只读故障仍在原预算内恢复，不重放未知写入。

共享运行时校验 Cookie 生命周期与作用域；固定 vendor 的增量补丁拦截身份变化、认证身份切换和受管重定向，并保留 503 的全池停止行为。注销回执、服务端会话消失与 License 观测分别报告。

## Migration

沿现有能力包更新取得完整脚本、vendor 与摘要，不单独复制插件目录。新入口拒绝旧 `managed-sessions-v1` 二进制；结束自有旧管理会话并重启受影响宿主 MCP 后，验证实际受管调用。Overlay 先更新共享 CapabilityRoot，再刷新各 ContextRoot。

保留 offline、明确禁用、旧 owner、熔断与未知结果；更新不自动解禁或启用 Cookie 格式假设。目标经核验后才配置私有格式绑定，详情见 `docs/guides/iris-managed-sessions.md`。回退保留未知结果，旧运行包不具有本次生命周期保障。

验证入口：`scripts/tests/atelier-session-lifecycle.tests.js`、`scripts/tests/iris-session-vendor.tests.js`、`scripts/tests/iris-session-migration.tests.js` 与插件 `deploy-recovery.test.cjs`。实际运行结果与限制归 `maintenance/validation/iris-cookie-lifecycle-2026-10-31.md`，不以发布记录代替真实验收。
