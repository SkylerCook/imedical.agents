# 范围基线统一为 TXT

移除 ProjectItem XML 清单解析及生成，版本清单、纯采集和 source-sync 共用严格 TXT reader；源码 XML 导出、编辑、增量和回退包保持原协议。

## Migration

更新框架取得 doctor/*.txt 和新 reader；旧公共 XML 文件随 Git 更新删除，不保留兼容副本。项目私有范围需从对象列生成 UTF-8 TXT，后端含扩展名，Web 以 / 开头，不能仅改扩展名。build 输出使用 .txt，compare/plan/project-plan 和 source-sync --map 使用 TXT。人工工具重新取得新版 ZIP，使用 -ListFile，-Baseline 已移除。旧任务保留原回执与已取得源码，用原工具结束旧任务或新建任务，不改写范围/运行时摘要绕过恢复检查；远端资格按原契约复核。
