# Git 主线部署保护

前后端部署使用固定 Git 基线与隔离三方合并产物；再次覆盖和不确定结果进入用户决策。本地源码及暂存区不接收服务器差异。

## Migration

部署前使用 deploy-guard.js init 建立需求会话。前端执行增加 --demand；后端 compile.js 改用 --project-root、--demand、--files 和显式 --execute，原位置参数上传被阻止。安装/更新机制不变；同步整个 coding-iris-plugin 及 vendor/sftp-server，不能只更新入口。

用户私有部署状态不随插件更新删除。详见插件 references/deployment-protection.md。

## Validation

Windows Node 专项模拟验证；跨平台矩阵由 deployment-protection.yml 执行，未运行平台不宣称通过。真实接口验证与模拟结果分开报告。
