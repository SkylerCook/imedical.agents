# 初始化闭环与配置诊断

初始化沿编码 owner 分别维护源码和服务器编码，复用已知连接与实际运行时路径，在既有授权内生成受管索引。配置生成先校验对象结构，集中报告缺失字段，非法 JSON 诊断避免输出配置原文。共享配置写入保留其它 MCP、扩展字段和显式禁用。

普通更新取得插件及共享 scripts 后生效，既有私有配置位置保持兼容。验证范围与剩余现场验收见维护日志。
