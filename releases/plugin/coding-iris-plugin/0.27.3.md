# 删除普通调用的 License 资格门槛

- 公共准入不再要求 qualification.status/reference；普通查询、SFTP 上传和编译不因未登记或历史证据缺失而停止。
- MCP 在本次调用核对真实目标与退出，不再要求历史 processExitVerified；会话迁移不再生成 qualification.pending。显式禁用准确报告 remote-policy-disabled。
- 保留连接复用、串行、实际资源退出、写入授权、未知写冲突及失败不重放；既有大批量文件导出与多会话资格保持原协议。
- 已部署工程完整更新根 scripts 和 coding owner，并结束旧管理会话、重启宿主 MCP；普通 Write 更新复用 iris-development-config-v1 自动清理废弃字段、空资格登记与冗余默认值，DryRun/Check 只预览。真实导出证据、连接、显式禁用、有效预算/共享池、私有扩展保留，旧 Cookie 格式绑定自动删除；恢复资料不删除，无需补证或手动清配置。

- 同名同域同路径的 Cookie 值更新不再被误判为身份变化；Node 与 managed-sessions-v3 vendor 使用最新 Cookie，仍保持账号/目标隔离、失效与作用域检查、不重复认证及禁止自动重放。更新必须包含新 vendor 和匹配摘要。
