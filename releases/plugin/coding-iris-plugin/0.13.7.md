# coding-iris-plugin 0.13.7

修正 Overlay 将读取范围与写入范围混同的规则：允许围绕当前需求只读调查已声明 GitRoot 或项目注册表明确映射的相关源码仓库。SourceRoot 仍为默认修改范围，模块外写入需明确授权，路径解析与工具写入门禁保持不变；backend-only 身份不因读取前端参考而改变。

## Migration

先同步共享 CapabilityRoot，再在已授权的项目上下文维护中定点合并旧模块 AGENTS 的读写范围条款，保留自定义内容。普通更新不自动覆盖 AGENTS，无文件清理；边界见 docs/workspace-overlay.md。commit 为变更前源仓基线，发布提交由 Git 历史追溯。
