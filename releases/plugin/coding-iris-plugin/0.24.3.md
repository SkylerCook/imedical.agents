# 修改前先同步并提交服务器基线

落实现有 connected＋project＋按需导出契约：待修改文件无论本地是否存在，都先完成 before-edit 同步；服务器变化或首次纳入基线先形成独立 export 提交，无变化不建空提交，再开始需求修改。普通 export 直接写源码在请求前停止并指向 source-sync，probe／独立 staging 继续用于参考。复用原现场保护、基线确认、提交授权及恢复机制。

正常更新完整能力包及已启用规则即可；旧 export 直写源码的项目调用改走 source-sync，不自动修改项目入口或配置，不迁移、删除旧恢复材料。标版、离线及其它上下文分支保持原契约。
