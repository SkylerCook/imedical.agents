# coding-iris-plugin 0.14.0

iris-demand-entry 改为面向 BOSS 两个填写框的简洁模板：名称使用 `{IRIS}`，缺陷描述为操作步骤、预期结果、实际结果；功能/改进为需求说明、操作步骤、预期结果。文本和 Excel 复用同一正文。用户、安全组、科室按需写入步骤，验收限制按需备注，验证状态保留在交付说明。
