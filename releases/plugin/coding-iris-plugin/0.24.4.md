# 初始化与已部署项目自动补齐开发配置

修复 coding-iris-init 未把必需配置生成与 Check 纳入初始化验收的缺口。复用 source-sync 的 configure 入口，并通过现有 manifest configMigrations 接入已启用项目普通 Write 更新，自动创建缺失开发声明及按需远端策略；available/disabled 不处理，DryRun/Check 保持只读。已有 JSON 字节、未知字段及旧模式缺省保持；机器声明缺失时自动更新先生成兼容空声明，不改变旧同步计划指纹，模式/环境待确认明确报告，Agent 按事实补字段。私有文件忽略、跟踪与链接检查在生成前执行。

远端策略初始禁用、资格 pending；配置、远端资格与服务器基线分别报告，仅完成本地配置不代表远端准入或 before-edit 已通过。更新不连接医院，不创建 Git 或空 source-sync 目录，基线由真实同步任务建立；补显式模式前核实旧任务的指纹及恢复条件，提交和部署仍沿原授权。

已有项目无需额外运行初始化即可在正常更新时补缺文件，也可单独执行 configure Write/Check；原有配置不重写，无旧恢复材料迁移或清理。更新器算法、thin-index 及 sparse 范围不变，新增迁移复用 JavaScript 核心和 Windows PowerShell 薄入口。隔离回归纳入既有 Windows/macOS/Linux × Node 22/24 CI，更新集成覆盖启用状态分流和重复执行。
