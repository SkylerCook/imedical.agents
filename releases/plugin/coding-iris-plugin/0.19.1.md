# 编译后 Storage 回填与表类注释规范

修复新增持久化类编译后本地缺少 Storage 的缺口。direct/guarded 共用编译后回读及整批核对，仅回填指定类的 Storage；保留本地业务代码、BOM/换行、暂存区和 Git 历史。覆盖字段演进，guarded 保存编译后部署与本地快照，后续检查复用最近部署映射，服务器合并代码不回写。

非 Storage 变化、映射删除/重排、未知格式和本地并发修改停止；编译成功但回填未完成明确报告远端已编译与本地同步状态，不自动重试或回滚。受管夜跑回填改变源码指纹时保留冻结版本复审门禁并挂起交接。

在现有 CLS 命名与格式规范中接入持久化表类注释：新增表类、属性和索引使用业务标签与纯文本说明，兼容历史别名，核对 SQL 投影并保护声明及 Storage。规则由后端编码与 Review 入口加载，现有格式脚本不增加标签解析或表结构文档生成能力。

已部署工程通过正常能力包更新取得，无配置迁移、旧文件清理或会话重建；旧失败/未知状态仍按原流程核实恢复。Windows 本地模拟与回环 CLI 验证不替代真实 IRIS 编译或非 Windows 矩阵。commit 为源仓基线，不表示本轮已提交或发布。
