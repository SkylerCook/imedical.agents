# 补齐菜单同步的可重复采集入口

修复现有 iris-menu-sync 每次依赖 Agent 临时适配采集的问题，固化分页、安全组动态选择、输出分段与无 ID 节点适配，保持原离线 plan/apply 与快照 schema 兼容。增加本地来源登记、方法摘要核验、带校验和的断点及异常删除/空组停止，采集证据随 generation 原子发布，失败保留旧快照。

支持指定时区的月度跳过检查：当月已有完整成功快照时不连接 MCP，可由宿主平日检查补跑，普通手动刷新不受月度限制。

用户可在目标工程授权登记后由宿主定期调用；任务不自动部署服务端、修改权限或提交 Git。正常更新能力包后登记实例，旧快照不迁移、不删除。未更新业务副本可由维护能力包入口显式指向目标工程试跑，不复制未提交文件。跨平台结果以专项 CI 实际执行为准。
