# 统一 IRIS TLS 缺省值并完善系统 CA 与诊断

初始化模板和连接入口缺省 TLS 校验统一 false，已有显式 true 保留。编译、导出、晋级与 Broker 不再使用相反默认值；MCP vendor 与 Node 使用同一运行配置。

显式开启校验的 Atelier 合并默认与系统 CA，专用 CA 优先；旧 Node 不自动降级校验，证书错误给出能力提示。安全错误码跨 IPC 和外层 JSON 保留，不携带原始异常或凭据。

更新根 scripts 与插件并重启旧托管会话；无需改写私有配置，无 vendor 二进制变化。缺失 TLS 字段的旧项目会采用 false；显式 true/false 均不修改。业务部署由用户执行。
