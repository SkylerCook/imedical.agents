# 支持已有 SQL Storage 类追加字段映射

受管后端部署允许新持久化字段在既有 `^` 分段的 SQL 数据节点中追加未占用的尾段。预检核对有效 SQL 字段名、旧映射、全局访问路径和服务器基线。上传与编译回读识别服务端序列化的映射顺序，并继续拦截段号与映射内容变化。

已部署工程按正常能力包更新取得脚本和规则。继续使用原连接配置、部署入口和会话，沿原流程处理历史失败状态。
