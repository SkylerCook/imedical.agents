# coding-iris-plugin 0.13.1

修正知识检索路由过于局限于菜单定位的描述，统一到 IRIS 通用规则：模型根据当前信息和查询收益自主选择本地知识检索，无需用户点名或另行确认，也不设为每次任务的必经步骤。通用、前端、后端入口复用同一原则，已有源码不排除查询业务背景；证据充分或资料不可用时继续原工作流。平台 API 查询与业务知识检索分开表达，远端读取、同步和写入授权不变。

正常更新并重建 enabled 插件 thin-index 即可取得新描述；项目 AGENTS.md 仍经已有规则索引/技能发现进入，不自动改写业务入口。不改变脚本接口、共享资料或项目快照。commit 记录实施基线，发布提交由 Git 历史追溯。
