# 离线 CLS 源码出包门禁

框架 Pack 发布前检查实际待交付 CLS 的变更行。内置解析器异常、ObjectScript 错误或命中 OS001、OS002、OS003、OS004、OS006、OS008 会终止打包。CLS Review 支持 --base-ref 复用任务基线，与 Pack 共用变更行语法检查；OS008 区分分支保护、赋值和表达式比较。更新能力包可同步插件及 Windows x64 vendor 运行时。

后端 Review 增加 OS007 传统错误陷阱收尾及 OS008 命名空间切换检查。

标版后端 Review 新增 OS005，新增业务数据或业务配置持久化必须走表，临时 Global 放行。

受管源码新增 review，读取冻结基线。OS008 拦截混合直接入口，待复核项按入包字节校验。标版源码 Pack 校验整份变更的 i18n 结论，覆盖仅前端变更。

OS008 排除条件编译未选中的保护，保护依赖未解析的预处理条件时要求按目标构建复核。
