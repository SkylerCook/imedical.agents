# coding-iris-plugin 0.15.3

将 CLS 提示完善为命名与格式唯一事实源，编码入口与 Review 共用；新增代码使用确定默认值，用户与项目显式规范优先，历史接口保持兼容。撤回后条件内部一律禁止空格的断言，更新类模板。

普通能力包更新即可取得规范，无业务代码迁移或旧文件清理，不自动同步真实工程。commit 为实施基线，发布提交由后续 Git 历史追溯。
