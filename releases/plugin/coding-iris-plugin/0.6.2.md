# coding-iris-plugin 0.6.2

优化 `iris-demand-commit` 的提交消息和日常执行性能：标版首行使用独立的简短菜单/功能摘要，完整需求保留在第三行；新计划按仓库一次性读取 porcelain v2 状态，并将 index blob、文件模式/状态与工作区字节共同纳入防漂移指纹。明确授权后可用 `apply --verify` 在同一进程完成提交和验证，普通业务需求不运行框架专项测试；pull、精确路径提交、无关改动保护和禁止 push 的安全边界保持不变。
