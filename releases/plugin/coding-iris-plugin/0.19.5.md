# 补齐注册类、方法与变量注释约定

将现有 CLS 表类注释扩展为统一的 ObjectScript 注释约定，明确非表注册类/DTO 的职责说明、ClassMethod/Method 的参数与返回契约、结构引用及方法体自然语言变量说明。Param 按参数名区分，其他标签保持单次声明；属性 Description 与索引注释按实际需要填写，兼容历史标签及续行。

注册类模板补充类、方法和可独立核对的调试调用注释，保留原声明和方法体。编码与 Review 入口共用同一规则，不执行 Debug，不增加标签解析器、文档生成器、编译或提交门禁。

正常更新能力包与已启用索引即可取得，无配置迁移或旧文件清理；已有代码不批量补写注释。真实宿主对规范的执行仍按既有 P2 队列观察。commit 为源仓基线，不表示本轮已提交。
