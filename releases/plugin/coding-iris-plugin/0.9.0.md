# coding-iris-plugin 0.9.0

更新默认将既有标准 SFTP 启动参数刷新到 vendor，无需预先选择 runtime。保留连接字段和禁用状态；缺失服务不创建，自定义参数不覆盖。

## Migration

需要保留外部实现的项目显式设置 sftp.runtime: custom。运行前仍需准备 vendor Python 依赖和可信主机密钥；更新不会自动安装依赖或连接服务器。
