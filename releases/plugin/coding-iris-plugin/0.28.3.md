# 编码确认与配置迁移换行兼容

confirm 使用行内空白匹配，避免字段替换吞掉 CRLF 中的 LF。显式确认时按主要换行风格修复单 CR，保留 BOM。迁移读取兼容 CRLF、LF、单 CR，已有显式编码配置保持字节不变。普通更新同时取得根 scripts 的 Pending 区块合并修复，保留人工内容与已有字段。

需求交付类型迁移及旧导出覆盖表读取兼容单 CR。前端编码已确认时请求 binary 原字节并按配置解码，保留末尾换行与服务器摘要；未确认时沿文本 staging 调查。根恢复 CLI 返回 poolId，优先报告 pool 定位失败，保留未知写核实与历史记录。
