# 医院源码导出 EXE

状态：Windows 便携版；已完成本地回归及一个授权环境的单会话小样本测试。运行入口为便携包中的 `IRISSourceExporter.exe`；PowerShell 是内置工作入口，不需要使用者手工准备 TXT 或输入命令。

## 目标与边界

- 主界面填写医院配置、Atelier URL、Namespace、用户名和隐藏密码；可选择用 Windows CurrentUser DPAPI 记住密码，配置保存在用户 LocalAppData/ImedicalSourceExporter，不随源码交付。
- 粘贴对象或导入 UTF-8 TXT；也可选择版本范围并提供医院补充对象。自动生成批次目录、files.txt、job.json，原件和回执归批次 export/。
- 安全 1/200ms、均衡 4/100ms、快速 10/50ms。并发会话硬上限 10；多会话先做每会话一个对象的小批试验，再由现场核实预算和资源回落。客户端不能以 Cookie 数或退出 HTTP 状态推断 License 单元。
- 一个后台持有会话池。相同目标、Namespace、凭据、会话数量和运行时的连续批次复用 Cookie；身份改变先关闭旧池。空闲 120 秒注销，无保活请求。
- 点击停止只停止新请求，等待在途请求结束；503 或其他异常停止派发，注销失败和异常遗留状态阻断后续导出。人工恢复必须记录现场核实依据。
- 每批取得源码后，保留会话期间回执仍为 partial/sessionRetained；显式断开或空闲回收完成后更新退出结果，只有全部取得且退出核对通过才为 complete。交付原件前需核对该最终回执。
- 当前仅支持 Atelier；不包含截图示例中的 Caché/Ensemble 兼容桥，不绕过 TLS 证书校验，不导入、编译或修改服务器对象。

## 构建与验证

从仓库调用 `tools/iris-code-export/build-gui.ps1`；构建电脑使用既有 Node 生成版本清单及 Windows .NET Framework C# 编译器生成原生窗口。正式 ZIP 落 `tools/dist/iris-code-export-gui.zip`；构建暂存目录自动清理。解压运行需要 Windows PowerShell 5.1 与 .NET Framework 4.5 或更高，不要求现场安装 Node/Python/Git。

GUI 复用 `export-iris-code.ps1` 的读取、Cookie 检查、摘要、恢复、输出和退出逻辑；`gui-worker.ps1` 管理跨批进程生命周期。共享框架 `docs/guides/iris-managed-sessions.md` 是生命周期设计参考；独立 GUI 不声称已经接入框架 Node IPC，也不与外部 IDE 或其它电脑共享预算。

本地回归：`node --test scripts/tests/iris-export-gui.tests.cjs`。测试用 127.0.0.1 模拟服务计数认证、请求、峰值并发和注销，不访问医院。

## 使用

1. 将 `iris-code-export-gui.zip` 完整解压，双击 `IRISSourceExporter.exe`；EXE 与脚本、catalogs 必须放在一起，不要只复制 EXE。
2. 填写连接、保存根目录和医院配置名称，点击“保存连接配置”。勾选记住密码才保存加密密码；取消勾选后再次保存会移除已保存密码。
3. 粘贴完整对象名或导入 TXT，也可选择版本。默认安全速度，先保留“小批试验”，点击“预览并开始”。预览不连接服务器。
4. 核对小批结果后取消试验，再导出完整清单；“继续已有批次”选择该批次的 `job.json`，自动核对并跳过已取得且摘要一致的文件。已全部取得但会话仍保留的批次，请先断开再恢复。
5. 多会话须先针对当前连接、凭据和速度完成小批试验，现场确认预算及资源回落后勾选预算确认。该勾选是操作人员声明，不是服务器 License 自动资格检测；变更连接或速度会清除此声明。不具备现场证据就保持单会话。
6. 同一窗口可连续开始多个批次；结束时点击“断开并核对退出”，或空闲 120 秒自动注销。核对 `export/baseline-state.json` 最终结果。停止等待在途请求结束，异常遗留会阻断新连接。

批次与配置互相独立。版本只定义范围，读取的是当前实例源码；缺失对象仍为 partial。界面目前提供 TXT/粘贴及版本选择，显式 Web 路径映射沿 README 的命令行入口。

## 验证边界

- Windows PowerShell 5.1 本地模拟验证 1/4/10 会话、跨批认证复用、空闲注销、503、取消、异常进程退出阻断、恢复证据、身份切换及断点续取。10 是客户端会话上限，不是承诺占用 10 个或更少 License 单元。
- 原生窗口自检覆盖 DPAPI 往返、取消密码保存、结果列表和预览。实际窗口已执行预览、小批、两轮连续导出、断开和关闭。
- 一个授权环境仅做 1 会话：小批 1 个系统对象，连续两轮各 2 个系统对象；两轮认证次数分别 1 和 0，断开后均 complete/logoutVerified=true。未做真实多会话压力测试，未独立验证实际 License 回落。
- 本工具的互斥和预算只覆盖本机本用户自己的导出器，不合并 IDE、其它程序或其它电脑的连接。异常断线下无法保证服务器即时释放，工具会保留阻断状态，需要现场核实后登记依据。
- 打包器逐文件校验 ZIP SHA-256；包内 manifest 可核对内容。更新时完整解压到新目录，已有配置保留；未关闭的旧窗口须先退出。旧批次绑定运行时摘要，不能绕过不匹配检查。
