# Agents Workbench 原型视觉规范

本规范记录本轮经浏览器截图检查的现有界面改进，不改变工作台计划及真实后端边界。

## 方向

浅色中文桌面工具，保留深蓝工程导航与青绿色主操作。工程名称是顶栏唯一主标题；页面标题说明当前任务。去掉英文装饰眉题、字符图标与无信息量的插画，不使用展示型动效。

## 可复用样式

- 事实源：`refinement.css` 中的 CSS 变量及共享组件；既有页面布局仍在 `style.css`。
- 正文 14px，表单标签 13px，辅助信息 12px；页面标题 22px，工程标题 24px。沿用系统中文字体，无在线字体请求。
- 主文字 `#213346`，辅助文字 `#526576`，页面底色 `#f3f5f7`，白色表单，分隔线 `#ccd6df`，主操作 `#08756d`。
- 错误、警告、成功各有文字说明，不能仅依赖颜色。普通状态弱化，主要操作保持突出。
- 控件至少 36px 高，表单输入约 38px；焦点使用 2px 清晰描边，Tab 顺序跟随阅读顺序。
- 工程配置在 1280/1920 宽度使用主表单与来源侧栏；更窄时来源移到下方。宽屏内容限制 1520px，不无限拉宽。
- 同组字段双列紧凑排列；端口使用窄列。区块间隔 16–24px，字段提示紧邻控件。

## 配置交互样板

`config-page.js` 提供工程信息、IRIS 连接、凭据操作、来源与作用域、草稿、页内修改预览和保存反馈。相关高级配置放到来源侧栏，避免抢占主任务位置。

凭据采用保留、模拟替换、显式清除；原型不采集任何真实密钥文本。共享个人配置单独提示跨工程影响，不混进工程保存。

草稿按已有工程演示状态持久保存；失败保留输入。保存和验证分别表达，部分完成保留检查入口。页面顶部“状态验收”可展示加载、空态、失败和部分完成，不执行真实后端。

## 本轮验收

- 已用内置浏览器检查 1280×900 与 1920×1080 配置页；无横向溢出。截图迭代移除了配置页标题前的快捷操作带，减少顶部空白。
- 已验证非法端口错误提示与焦点、草稿刷新恢复、模拟保存失败、部分完成后检查、保存成功。验收端口已恢复原演示值。
- 已检查加载骨架与完成读取、空态与创建入口、共享 BOS 凭据面板、插件页面共享视觉样式。
- 已检查控件标签与连接地址到端口的 Tab 顺序；未进行完整屏幕阅读器或真实客户端验证。
- Console 无错误／警告；该轮 Network 仅访问 127.0.0.1 的静态资源、插件目录与手册目录。
- Impeccable detector 执行一次，发现旧样式的侧边粗线及彩色阴影，已定向移除。检测结果不代替截图与交互验收。

真实工程绑定、凭据加密、配置写入、SQLite 和宿主执行仍未接通；本规范不将演示验证记为真实业务验收。

## 配置布局与共享外壳

工程配置表单通过 `.config-sample` 限定布局；侧栏、顶栏、导航高亮使用全页共享样式，切换页面不更换主题。采用 184px 浅色侧栏、紧凑项目栏、单个表单容器与分隔线，取消常驻来源右栏。来源及更多配置渐进展开；正常状态为单行，失败和部分完成保留明显反馈。保存区回到正常文档流，不覆盖字段。

本轮检查 1280×900 前后画面、1920×1080、1280×600，验证长连接文本、字段错误、未保存、失败和部分完成；发现输入与下拉高度不一致后统一为 38px。浏览器观察未发现横向溢出，保存区 computed position 为 static。对照截图在会话中展示，未保存独立图片文件。表单布局样板保留；共享外壳已统一，避免进入配置页时变色。


## 实际工程工作台复审修订

`actual.html` 使用 `workbench.css` / `workbench.js`，与虚构演示入口分离。正文 15px，表格 14px，辅助信息 12–13px；表格行垂直 padding 11px。已启用使用绿色文字与浅绿底，同时保留明确状态文字。导航按工程、协作与资源、维护分组，采用统一 24px viewBox 线性 SVG，实际显示 17px。

页面按用途分别使用行动列表、能力目录、插件表、配置来源与编辑对话框、客户端发现表、连接面板、资料目录、双栏手册、保存回执列表。手册默认展开使用手册，不再以空白正文作为初态。

设计参考：Tabler 的设置分组与表格密度（https://github.com/tabler/tabler）、Ant Design Pro 的浅色管理框架（https://github.com/ant-design/ant-design-pro）。只参考交互组织，未复制源码或引入依赖；没有采用 shadcn 的 React/Tailwind 技术栈。

前述“真实配置尚未接通”为早期样板记录，当前实际能力以 README 为准：个人配置与 IRIS 同步保存已接入；部署、插件执行、宿主自动调用及向量构建仍有明确缺口，不用视觉状态代替执行证明。


本轮复审验证：1280×900、1920×1080 与 1280×600；九页路由无横向溢出，Console 无错误/警告。实际项目的工程表单含 IRIS、Web、SFTP 三组，凭据不回显，真实预览未保存。合成工程在浏览器完成修改主机、预览、保存、读回成功与重新打开后回执可见；合成目录和临时服务已清理。截图在会话中展示，没有独立保存图片文件。浏览器截图复审不等于屏幕阅读器全量验收或远端认证验证。
