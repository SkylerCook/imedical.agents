# AGENTS.md

## Plugin Purpose

`codegraph-query` provides a read-only query layer over the project-local `.codegraph/codegraph.db` database generated by the CodeGraph CLI.

Use it for frontend and script-side code location, direct caller/callee checks, route lookup, and first-pass impact analysis. CodeGraph results are only candidate evidence; conclusions must still be verified against source files, project config, and tests.

## Boundaries

- This plugin does not build or modify the CodeGraph index. Use `codegraph status --json .` and `codegraph sync .` from the project root when the index is stale.
- `.codegraph/` is local runtime data and must not be committed.
- The query script is read-only. It reads `CG_DB` or defaults to `.codegraph/codegraph.db`.
- The current CodeGraph index may not cover ObjectScript, CSP server code, macros, Globals, dynamic calls, or remote IRIS behavior. Use `iris-codegraph`, IRIS coding rules, MCP tools, `rg`, and source inspection for those paths.

## Entries

- `rules/codegraph_query_usage.md`: usage rule and verification boundary.
- `skills/codegraph-query/SKILL.md`: task workflow for CodeGraph DB queries.
- `scripts/cg-query.js`: read-only SQLite query CLI.
- `scripts/generate-plugin-thin-index.ps1`: wrapper around the root canonical thin-index generator.

## Safety

Do not copy MCP connection facts, credentials, tokens, namespace values, remote paths, or project-private business facts into this plugin. Query output is an analysis aid, not a deployment or runtime validation result.
