# 布局与生命周期排查

按出现的症状读取对应段落。先核对当前工程公共能力与实际时序，再选择最小修复；本文件不提供必须安装的统一布局层。

## 公共接入与主题

从实际入口追踪 head 展开后的资源顺序、主题选择、body 输出和公共适配。采用 `DOC:HEAD` / `docBodyAttr` 的工程同时核对两者；其它加载机制按当前源码调查，不硬套路径。读取实际加载资源与计算样式，区别未加载、选择器未命中、优先级被覆盖及重复适配。

先识别哪些尺寸来自控件原生 options、生成包裹层、公共 layout 接管标记和页面业务容器。公共已经接管的面板继续由公共负责；缺口才通过原生 API 补齐，保留原回调。主题专属视觉与通用尺寸分开验证，并按工程支持范围检查普通、焦点、禁用和等待状态。

## 对齐、换行和多余滚动

1. 先量目标 frame，再量宿主、区域、实际滚动容器和内容的 `clientWidth/scrollWidth`；核对 border、padding、split、滚动条及 `box-sizing`。宽度相等只证明该时点无横向溢出。
2. 留白重复时核对父子各自所有权；选择器失效时读最终匹配与层叠来源。根据实际宿主限定适配，独立页及弹窗保留其自身边界。
3. 控件同格还有链接、图标或按钮时，给这些元素明确剩余空间关系，再调用控件 resize；整格宽度不等于控件可用宽度。
4. 表格提前换行但右侧空白时，核对每行真实列数、colspan/rowspan 与嵌套表格，再判断 `table-layout` 的影响。动态字典保留业务内容，用长短项作对照。

空白条也可能来自控件配置。当前 HISUI `datagrid` 按 `toolbar` 是否为真值决定生成容器，`[]` 仍会创建空工具栏；无工具栏场景采用原生的 `null`，有按钮的配置保持。按目标版本核对选项语义，优先修初始化配置，不用隐藏整个工具栏的 CSS 影响操作页面。

## 异步内容与侧栏

记录“区域外宽变化”和“内容可用宽变化”是否都能触发已有适配。异步字典使内容变高后可能新增垂直滚动条，区域 onResize 未必触发；先证实该差异，再选择原生事件或受控内容观测。合并调度实际 resize，限制有效变化并处理销毁；不能用隐藏溢出或固定滚动条宽度掩盖原因。

侧栏回调可能早于动画与 layout 开关收尾。核对真实组件时序，分别测展开、收起及快速切换后的最终状态；需要延后时绑定已核实的完成信号，忽略过期回调和已移除区域。某个动画中间值不作为最终布局结果。

## 首屏与重建

区分主题属性晚到、资源失败、原始 HTML 提前绘制和初始化异常。用慢加载及前后对照确认，不以一次刷新未复现排除偶发问题。

确需局部展示保护时，先核对公共是否已有机制；保持初始化所需布局测量，并保证成功与异常都能释放。以实际生命周期结束为依据，不等待业务数据、不覆盖公共全局回调，也不用猜测秒数。某工程的 opacity 门控只是可选方案，不直接推广到全部页面。

文案或工具栏在加载后闪变时，检查初始定义、refresh 与数据回调重建是否有多个来源；优先修真实定义。重复打开/关闭时核对组件和宿主清理次序，保留既有刷新行为，避免销毁后继续 resize 或重复挂载事件。

## 模板预览与实际打印

先分清数据协议、模板坐标、屏幕承载容器和实际打印入口。仅调整预览留白、阴影、按钮位置或缩放时，将差异放在屏幕外壳，保留 XML 字段、模板坐标、DOM ID、打印参数与事件；需要改变打印输出时单列其范围。渐变与滚动边界按所属视口统一处理，避免各内容块重复绘制造成断层。

增加外壳或展示保护前，核对既有渲染器的定位、查找和清理选择器。隐藏方式可能改变 `:visible` 等消费者的结果，空态、清空及重新选择的内容替换需沿原契约保持；不能因一个模板样本便统一禁止某种隐藏方式。分区横线与牙位十字等图形按语义或已证实的模板特征区分，样本中的宽度阈值只作局部启发，不升级为所有 XML 的分类规则。屏幕预览通过与实际打印输出验收分别记录。

## 选择验证

按共享协议的[范围与停止条件](../../../agents/_shared/testing-protocol.md#验证范围与停止条件)，仅取能回答当前风险的场景。首次空态、查询展开/收起、页签切换、内容增减、字典重载、重复打开、慢加载及初始化失败是候选项；宽度和主题也采用实际受影响集合，不组合成每次必测矩阵。

可在明确目标 frame 中使用 [collect-ui-metrics.js](../scripts/collect-ui-metrics.js) 采集只读尺寸与限定样式。多匹配先缩小选择，不取第一个元素当成目标；测量后还需检查可见状态、对应交互、实际资源版本及相关 Console/Network。完整执行和交付沿 [testing-protocol](../../../agents/_shared/testing-protocol.md)。
