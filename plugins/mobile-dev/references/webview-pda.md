# WebView 与 PDA 专项

仅命中对应设备能力时加载，不将设备厂商特例作为通用模板。

## WebView

- 核对原生入口、H5 所属工程、导航/返回、JS bridge 和登录态归属；H5 修改交给其 owner 流程。
- 检查页面销毁、异步回调和资源释放，验证加载失败、返回与恢复。
- 保持既有可信来源边界；新增 bridge 方法核对来源、参数与业务权限，不通过放开 TLS 或任意页面访问掩盖问题。

## PDA 扫码与广播

- 查当前设备文档和项目适配层，确认扫描输入走广播、键盘还是 SDK；action、extra 和权限从实际协议取得。
- 核对注册/注销生命周期、前后台接收、焦点、重复事件及一次扫描对应一次业务动作。
- 模拟输入只证明解析与状态逻辑。真实设备验证扫描、重复扫描、切后台和恢复；不具备设备时明确这些部分待验，不声称支持所有 PDA。
