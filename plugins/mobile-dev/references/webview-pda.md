# WebView 与 PDA 专项

仅命中对应设备能力时加载，不将设备厂商特例作为通用模板。

## WebView

- 核对原生入口、H5 所属工程、导航/返回、JS bridge 和登录态归属；H5 修改交给其 owner 流程。
- 检查页面销毁、异步回调和资源释放，验证加载失败、返回与恢复。
- 保持既有可信来源边界；新增 bridge 方法核对来源、参数与业务权限，不通过放开 TLS 或任意页面访问掩盖问题。

## PDA 扫码与广播

- 查当前设备文档和项目适配层，确认扫描输入走广播、键盘还是 SDK；action、extra 和权限从实际协议取得。
- 核对注册/注销生命周期、前后台接收、焦点、重复事件及一次扫描对应一次业务动作。
- 模拟输入只证明解析与状态逻辑。真实设备验证扫描、重复扫描、切后台和恢复；不具备设备时明确这些部分待验，不声称支持所有 PDA。

## Web 表单接入与白屏定位

复用当前工程的 WebView 宿主、登录上下文与 bridge。诊断按下列链路逐层取证，日志先脱敏。

1. 核对原生实际发出的 URL、编码、业务参数及页面操作类型，跟踪主文档请求和重定向。
2. 登录页或认证错误出现时，核对免密入口、视图授权和会话归属；TLS 错误单独记录。项目自签证书兼容沿已有明确授权和可信地址边界处理。
3. 页面空白或一直等待时，检查主文档/资源 HTTP 错误、Console 异常、bridge 注册时间和页面就绪事件。先确认渲染进程及调试目标仍存活，再读取现场。
4. 保存开始、成功、失败和关闭事件按现有业务契约处理；回调成功后核实业务状态。页面销毁时解除监听并释放 WebView。
5. 完整宿主验证导航图标、统一确认弹窗、侧栏展开/收起、键盘、滚动到底和底部按钮。表单片段预览与实际 WebView 分别记录结果。具体表单样式由 H5 owner 维护。
