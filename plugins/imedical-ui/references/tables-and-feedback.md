# 表格、分页与反馈

用于 IHOS 海蓝和 PURE 天蓝业务页的共性适配。控件与主题优先复用工程现有组件；HISUI 工程优先复用 HISUI。在当前入口、数据与权限契约下核对展示，不据规范示例新增业务能力。

## 证据与执行范围

1. 标明当前表格、查询/操作/分页分区及实际主题，再按本文件选择相关条款。
2. 明文要求保留必须、建议、可选强度；构件几何与页面示例只在其适用范围核对。
3. 操作权限、字段含义、行编辑、新增保存、默认排序及真实数据行为若要变化，先登记待核对，不混入展示修复。
4. 设计器中的拖拽、复制或调整示例说明不作为用户操作需求。

PDF来源、版本及 [风格适用范围](source-catalog.md#来源适用范围)见来源目录，下文页码为物理页码。PDF单方明文不直接成为PURE强制要求；MarkLion以资料族、相对文件、画板及完整GUID定位。

## 表格展示

来源：[PDF p37–38（对齐、行高、斑马纹与操作）](source-catalog.md)。

- 表格内容默认左对齐，可按业务场景调整；内容宽度一致时宜居中。涉及数值大小比较时宜右对齐，数字、金额字段右对齐。
- 按业务含义识别数值列；登记号、编码等数字串不能仅靠字符检测归为金额或数值比较列。
- **默认不修改原生表格行高**。例外：单元格内容要求完整呈现，不允许缩略、截断或隐藏时，可特殊配置行高。
- 表格默认须有斑马纹。具体评审已明确的合并行、汇总或主题例外按需求保留，不因一句默认要求移除已有例外。
- 横向滚动、纵向滚动、冻结区及表头/正文尺寸分别核对；不要用隐藏溢出掩盖列宽或容器问题。
- 核心重要信息及序号、复选、操作等结构列的固定位置按规范核对；需要重排列、改变操作上下文时登记业务影响后处理。

## 操作列与编辑方式

来源：[PDF p38–39（操作和新增修改）](source-catalog.md)。

- “是否可用/是否有效”等二元**展示**列须用“是/否”，可用文字颜色强调；不要用复选图形混淆展示值与可执行操作。
- 若当前列承担编辑或业务切换，先核对事件、权限、保存含义，再决定展示改法；不能只删除Checkbox后宣称完成。
- 识别度高的常用操作宜独立操作列，数量不宜超过5个；使用图标时须有Tooltip。
- 图标不能清楚表达功能时，可用文字超链接并宜独立列。保留原权限、行上下文、更多菜单及刷新入口。
- 行操作栏编辑、上方表单编辑、弹窗编辑是不同适用模式；复杂结构或父页面未展示的内容可采用弹窗。
- 原文对新增、修改与保存提出相应建议；本次纯展示适配保留当前模式，差异作为业务/交互待核对项，不自动改成统一CRUD流程。

## 分页与组合布局

来源：[PDF p39（通用/小分页）、p52（数据查询布局）](source-catalog.md)。

- 通用分页：表格底部分左右区域，左侧条目统计；右侧依次为当前页码范围、翻页操作和快速跳转输入。
- 小分页适用于窄面板。是否切换按实际容器与已有能力核对，不按某个示例宽度设全局断点。
- 查询、操作栏、表格和分页作为连续组合检查；兼容PURE的查询与表格间距为10px，仅IHOS独立使用时允许0px。
- 分页不得被额外容器白条、横向滚动层或固定操作栏遮住。保留每页条数、总数、翻页和查询后的刷新规则。
- 示例中的“1–10/共99条”、页码范围和每页数量不定义业务分页默认值。

构件来源：[PURE 控件-01](../../../vendor/imedical-ui-standards/pure-controls/res/控件-01按钮+表格+表单+其他控件/data.js)。

- 通用分页：`88e66e27-7acc-496e-b044-4c69cbad00a2`。
- 小分页：`86d6dd5f-f930-401f-8f05-83213d9a204e`。
- 表格底部分页组合：`f8f9af82-a6db-43f9-9ae9-34809e86dc19`，可见52px背景与1px边界；属几何采样，不产生全局分页高度覆盖。

## 提示与反馈的选择

来源：[PDF p40–43（Tooltip、气泡卡片、警告、全局提示、提示弹框）](source-catalog.md)。

| 类型 | 使用与强度 | 验证重点 |
| --- | --- | --- |
| Tooltip | 鼠标移入显示、移出消失；仅简短只读解释，不能放复杂内容或交互 | 纯图标有说明；优先上下方，三角归属正确，关键内容及按钮无遮挡 |
| 气泡卡片Popover | 可解释或承载关联操作；关闭按钮默认不配，可按业务加 | 不因有交互仍套用Tooltip；复用组件现有触发/关闭语义 |
| 静态警告 | 持续到关闭或问题解决；表单上方显示，多条全部可见，警告优先于正常提示 | 不自动消失、不覆盖其它内容；不能拿Toast替代持久警告 |
| 全局提示 | 简短操作反馈，顶部居中；宜3秒内消失或可手动关闭 | “宜”不改成所有消息固定3秒；加载等状态沿原业务生命周期 |
| 提示弹框 | 需用户选择后继续，通常1–3按钮；主题图标与渐变匹配 | 按实际内容与视口适配；示例按钮数量不授权删减业务动作 |

失败反馈应说明失败结果、已知原因和解决方法；原因未确认时如实表达，不能编造原因或用空态掩盖请求/存储失败。成功反馈与真实结果核对，不以HTTP成功或按钮关闭推定业务成功。

来源：[PDF p42–44（提示弹框与模态窗）](source-catalog.md)。提示弹框/模态窗最小474×274，顶部渐变固定高度；具体窗口按内容与当前屏幕适配，不能把最小值或示例尺寸当固定窗口值。小视口无法满足时记录约束并核对既有窗口策略，不强行制造裁切。

PURE说明“遮罩为黑色30%，顶部渐变高度不随弹窗大小改变”，见 [控件-02布局](../../../vendor/imedical-ui-standards/pure-controls/res/控件-02布局/data.js)，`307cce12-8639-4d86-847e-64dba61f66d9`。文字没有给具体180px，不能仅凭一个图形样本写成所有提示的通用高度。

## Family 差异与定向验收

- 保留主题的表头底色、边框、斑马纹、选中与hover反馈；通用列布局、语义对齐和生命周期问题可以共用适配。
- [IHOS海蓝表头样本](../../../vendor/imedical-ui-standards/ihos-seablue/res/控件-01按钮+表格+表单+其他控件/data.js) `79134d65-8d9e-4f43-8bab-7b0b34a79ba1`：底`#E3E7FA`、分隔线`#CFD5F5`；[PURE样本](../../../vendor/imedical-ui-standards/pure-controls/res/控件-01按钮+表格+表单+其他控件/data.js) `1558e4e1-4b16-4c25-8c49-8f6459cfe36d`：底`#F2F3F7`、分隔线`#E4E4E4`。只用于核对来源，不另造业务主题色表。
- 两种family覆盖空态、正常数据、长内容、超过一页、横/纵滚动及窄面板；加载/空数据/失败保持原契约区分。
- 核对冻结区、合并单元格、汇总行及主题特例；不因默认斑马纹条款取消已确认例外。
- 翻页、查询后刷新、重复打开和动态内容后，表头/正文/分页对齐且关键操作可达；原字段值、权限、handler与参数不变。
- Tooltip、Popover、警告和全局反馈按各自生命周期核对；关闭、重建后无重复事件或残留层。
- 技术测量只证明指定状态；实际资源、Console/Network、业务验证与用户视觉验收分别记录。
