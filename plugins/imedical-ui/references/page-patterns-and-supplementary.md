# 页面模式与补充构件

涉及登录、首页、关于、申请录入、步骤条或补充控件时读取。先确认真实页面模式，复用工程已有能力；不把示例页面变成所有业务的统一模板。

## 采用哪类依据

- PDF条款直接说明IHOS相应场景；PURE采用其对应构件/组合证据。未在PURE出现的比例、默认或交互要求保持适用范围，不因共用本页就自动推广。
- 构件图形可以确认形态和状态，不能定义业务数据、上传接口、日期范围、评分规则或持久化方式。
- 设计器的“选中切换类型、复制增删、拖拽调整”等说明排除；对产品状态有意义的结果与设计器操作分别记录。
- 规则强度、资料批次和证据类型沿 [source-catalog.md](source-catalog.md)。下文PDF页码为物理页码，图层按资料包、画板和完整GUID定位。

## 登录页面

来源：[PDF p45–47（登录布局）](source-catalog.md)。以下比例属于IHOS登录场景，不用于普通查询、弹窗或PURE登录的推定。

1. 居中模式将系统标题、表单和按钮垂直聚合，整体水平居中。有框模式为页面宽度30%的白色带投影卡片；无框模式无该白底和投影。
2. 居左/居右模式将登录区放在一侧，另一侧为插画；登录区域宽取页面宽的`1-0.618`，插画区取`0.618`，计算结果取整。
3. 上述IHOS模式中的表单采用固定宽度，不能把“区域按比例”误写为“所有输入按屏幕同比缩放”。具体表单宽度仍核对目标规范和可用屏幕。
4. 右上功能区包含语言、布局、有框/无框、主题切换。当前工程缺少功能时登记产品范围，不为匹配例图自动实现认证之外的新能力。
5. PDF对IHOS三主题要求插画图形一致、背景随主题变化；日间图形不透明度100%，夜间80%。本期海蓝/PURE比较不据此扩展夜间改造。

## 工作站首页

来源：[PDF p50–51（首页布局）](source-catalog.md)；[IHOS布局-02首页](../../../vendor/imedical-ui-standards/ihos-seablue/res/布局-02首页/data.js)，`92ecb839-50be-4b5f-9751-aaabc72d6e60`。

仅在目标确属该IHOS首页模式时采用：

- 顶部信息区占高15%，包含身份、工作站与页签，作为全局固定区域。
- 中部功能/数据区占高60%；其中左70%放常用入口及图表，右30%放关键指标卡。
- 底部动态列表区占高25%，以表格呈现并支持分页。
- 常用入口为8宫格图标加文字，图标56×56；支持横向扩展，不足8个时须隐藏左右箭头，整体左右间距80px。
- 图表卡片按1:1划分；指标卡垂直排列，名称限8字，超出省略并悬浮展示全称，内容左右间距30px。

这些是该首页的明文布局要求，不是所有工作站或业务表单的固定比例。本期PURE布局包没有同名首页画板，不能宣称上述比例已取得双family依据。

核查实际入口数量、长指标名、数据加载前后、图表尺寸和列表分页；真实指标、权限、导航地址与数据服务沿当前业务，不复制画板演示数据。

## 申请表单组合

来源：[PURE布局-09申请表单录入](../../../vendor/imedical-ui-standards/pure-layouts/res/布局-09申请表单录入/data.js)，画板`f2f45a67-930b-436e-b90c-c125f2a1e9f0`。

该画板是申请分组与底栏的组合参考，未据此取得所有申请业务的字段、默认、必填和流程要求。

1. 识别信息分组、内容滚动、关联区与操作栏，核对各层边距和高度的责任者。
2. 从真实表单保留字段ID、事件、字典、取值、权限和提交/暂存等动作；按图调整展示时不复制示例字段数量或保存路径。
3. 固定操作栏应始终可达；长内容在自己的区域滚动，动态字典、展开分区和窄容器后重新核对尺寸。
4. IHOS没有此同名申请画板；共性采用已证实的表单/按钮/容器规则，family差异沿对应主题及真实宿主补齐，不整页复制PURE外框到IHOS。

## 步骤条：状态类型与步骤数量分开

来源：[PURE控件-01按钮+表格+表单+其他控件](../../../vendor/imedical-ui-standards/pure-controls/res/控件-01按钮+表格+表单+其他控件/data.js)。

- `e5b0cbe8-4468-4ddb-83b1-493817bbe32e`明文：“当前流程还可能出现失败或告警状态”。按真实流程呈现，不为视觉样例新增失败/告警业务枚举。
- `d6e79141-a61e-4ebb-bf62-e01c55272d33`明文：“如需要可将序号部分换为图标”。保留可选强度。
- `3ed96bfc-d0aa-4cd7-92f5-b868b6deb645`是步骤条组，含水平/垂直、有无序号、带子节点和对齐变体；按真实流程与容器选择，不固定示例长度。

## 场景核查

- 登录/首页/关于只在对应入口检查，未涉及的页面模式不纳入本次改动；同family其它页面未因此获得通过结论。
- 补充构件分别检查正常、禁用、展开/关闭、长内容和动态数据后的可见状态；业务事件和真实结果独立核验。
- 两family分别记录共性与差异；只有单方来源时注明，不能把资料索引完整等同于全部运行态或正式评审已覆盖。
