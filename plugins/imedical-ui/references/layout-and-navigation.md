# 布局与导航

查询区、面板组合、导航、标签组、弹窗或滚动发生变化时读取本页。
先确定当前页面的宿主边界，再按相应场景选取规则；普通业务内容沿用原有契约。
资料版本和 PDF 原件见 [来源目录](source-catalog.md)，两种风格的差异见 [风格差异](style-differences.md)。
PDF条款按 [来源适用范围](source-catalog.md#来源适用范围)首先约束IHOS；PURE的强制判断须有对应证据，明确跨风格兼容条款可直接采用。

## 证据如何使用

- **PDF 明文**：保留页码、适用对象和例外，按当前目标风格应用。
- **构件参数**：记录画板、节点 GUID 和几何对象；与运行时组件盒模型核对后使用。
- **组合示例**：用于辨认区域关系、边距所有者和阅读顺序，不复制示例业务或全部尺寸。
- **设计工具说明**：切换变体、复制选项、按住 shift 拖动等操作只服务设计文件编辑。
- 相同 GUID 会跨资料族复用；来源定位同时包含资料族、版本、画板 GUID 和节点 GUID。
- 仅从截图目测得到的数值标为推断；读取结构化标注后再升级为参数依据。

## 先划分页面边界

1. 识别宿主导航、系统级标签组、业务内容区、嵌入页和窗口的所属层级。
2. 核对实际主题、已有组件和公共布局入口；从当前工程选择可复用实现。
3. 标明每层外边距、内边距和滚动由谁承担，再调整业务容器。
4. 页面嵌入宿主后，由宿主已提供的空间只计算一次；嵌入页保留内容内部需要的留白。
5. 同一业务优先共用结构、区域语义和组件配置，再补当前风格确有依据的差异。
6. 完成判据：每个新增间距都能指出所属边界和来源，两个评审风格没有重复留白。

PDF p45 的基础间距以 5px 为单位；同背景相邻面板间距 10px，不同背景相邻面板可无缝衔接。
其中“页面边缘贴合”属于 IHOS 布局要求，不能脱离宿主直接套到 PURE 业务内层。
PURE 标准查询组合示例的外侧 15px 由页面内容边界承担，不要求每个子面板再加 15px。

## 查询与列表

- 将区域辨认为查询条件、操作栏、表格主体、分页，保持查询与数据操作的语义分组。
- PDF p52 明确：兼容纯净版本时，查询区与表格区预留 10px；仅支持 IHOS 时无需额外预留。
- 同时支持两个评审风格的业务可复用该 10px 兼容口径，不必维护两套查询 DOM。
- 为操作栏和分页预留它们实际需要的空间；列表主体承担剩余空间及其数据滚动。
- 表单输入同行对齐；先计算标签、控件、图标、按钮和组间距，再决定容器分列或换行。
- 容器不足时保持同一字段组完整；保留标签与输入框的关联，不靠压窄单个下拉框凑一行。
- 标注中的示例列数、字段名称、查询按钮数及列宽不构成目标页面的数据契约。
- 固定查询高度改为内容适配时，同时核对标题、控件初始化和查询区展开后的列表高度。
- 工具栏复用组件配置和按钮能力；首次渲染即输出正确状态，避免渲染后按文案逐个改写。
- PDF p39 将通用分页和窄面板小分页分开；按容器选型，不把整页分页硬塞进小窗口。

主要来源：IHOS 查询画板 `006f6c86-b8ed-4606-8a0f-a2db91af7357`、PURE 查询画板 `fb1a8f86-8061-4bb1-934d-eac47eeeeb3c`。

## 面板与多分区

- 标题栏与内容区分别核对；PDF p27 的普通面板、带底色面板属于不同使用场景。
- 带底色面板常用于无默认左侧导航的页面左侧，例如患者列表，不作为所有表单背景。
- 普通标签组、可关闭标签组、系统级标签组、二级标签组分别选型，沿用组件语义。
- PDF p27–29：普通标题标签组的标题前有图标，标签部分不带关闭按钮；可关闭标签组另有规则。
- PDF p28 的四字标题、六字内容限制适用于竖向标签组；省略后悬浮展示全称。
- 可折叠查询侧栏切换后，核对相邻区域重新分配空间及内部控件尺寸，不只检查侧栏宽度。
- 滚动区域内的装饰背景归稳定容器，避免跟随内容滚动产生渐变接缝或重复背景。
- 长内容、空数据、无患者三种状态均使用同一布局边界；状态切换后不遗留占位宽度。

## 导航与系统级标签组

- 导航属于宿主时，业务页只接入已分配的内容区；全局菜单、标题栏、页签由宿主负责。
- PDF p48–50 提供顶部、左侧、混合三种导航组合；根据已有宿主选用，不在业务页重建导航。
- PDF p34：左侧导航超出容器高度时，滚动归最外层菜单区。
- 可折叠菜单和手风琴菜单同时展开能力不同；按现有业务和组件配置选择，保留用户当前状态。
- PDF p35 建议收缩导航初始展开；已存在持久偏好或业务默认值时，先核对再调整。
- PDF p29–30 的首页不可关闭、默认标签及溢出收纳涉及宿主行为，登记给宿主所有者处理。
- 图标、文字、关闭按钮及更多按钮应有完整可点击区域；省略文本仍能查看完整名称。
- 顶部功能图标的默认、悬浮和选中状态按所属主题资源处理，不在业务页硬编码另一主题颜色。

## 弹窗与固定操作栏

- 先分清提示弹框、业务模态窗、浏览器窗口，复用当前技术栈的窗口组件。
- PDF p42、44 与两套控件说明均给出最小 474×274；这是对应窗口类型的下限，不是统一固定尺寸。
- PDF p53–54：尺寸按内容和可用屏幕确定，空间足够时避免不必要滚动，外侧至少留 20px。
- PDF p44：业务模态窗的底部按钮居中，按钮之间及上下间距为 20px。
- PDF p21：查询区主按钮通常在次按钮左侧；独立底部操作栏主按钮通常在右侧，特殊场景可调整。
- 模态遮罩边界由当前宿主和交互需求确定；确认其是否覆盖系统级页签或当前页签。
- 背景顶部渐变高度固定，随窗口内容滚动的部分不重复绘制该渐变。
- 按钮栏保持可达；长内容只在其所属区域滚动，避免遮住底部操作或生成第二条页面滚动条。
- 组合例图中的 900×530、1040×550 等是样本尺寸，不据此固定所有业务弹窗。

## 业务交互另行核对

下列要求可能改变业务行为，UI 调整先记录对应差异，由有权确认的人决定后实施：

- PDF p26 的单选默认首项、同类别多复选增加全选，以及父子勾选联动。
- PDF p38–39 的新增空白行、双击编辑、上方表单编辑和弹窗编辑等模式选择。
- PDF p29 的首页固定、页签初始选中，以及 p34–35 的导航展开策略。
- PDF p53–54 的模态限制、移除遮罩、允许父页实时交互和特殊最大化策略。
- 对按钮顺序或主次的调整若改变快捷键、提交路径、权限状态或用户操作习惯，同样先核对。

## 验证对象

- 同一业务结构分别以 IHOS 海蓝、PURE 天蓝检查，记录共同完成项与仍存在的风格差异。
- 覆盖首屏、数据加载后、重复打开、侧栏展开/收起、页签切换及容器变窄。
- 检查各层可用宽高、滚动归属、标题和按钮可见性，以及控件初始化后的实际外框。
- 设计尺寸与工程实际支持尺寸分别验证；1920×1080 示例不代表所有终端均已适配。
- 技术诊断与人工 UI 评审分别记录，组件能渲染不等于两项评审已经通过。
