# BOS 夜跑 2.1 源仓验证

日期：2026-10-16。范围：框架源仓实现与本机合成验证；提交与推送以 Git 记录为准，未更新业务副本或写入真实服务。

## 已落地

- schema 2.1 显式接入；一个批次绑定一个 run，work item 按实际 Git 根归属角色隔离工作区。原 2.0 保持兼容。
- 启动前集中核验已有授权、源码/角色/数据策略、配置与真实能力；运行中受阻项挂起并留交接，框架不产生新增授权问题。
- 部署/编译/验收入口复核 work item、联合来源、授权、配置、额度与截止；回执消费、内容去重、共享部署回读复用及阶段计时复用原 run 事件源。
- 写测试的 fixture 检查及 retain/reset/delete 处置与资源退出分别判定；来源返修使旧复审、部署和测试不能满足新门禁。
- CLS 清单与部署共用 Class 声明解析；检查示例逐项保留退出码；编码/条件 i18n 前后复核、BOS 逐号及首次连接异常诊断写入既有流程。
- BOS 0.9.0、coding 0.19.0，各直接依赖补一个 patch 并接纳 coding <0.20.0；发布记录随源仓版本审计，commit 字段引用源仓基线。

运行契约见 [night-policy](../../docs/night-policy.md)，项目适配及数据成本方案见 [night-acceptance](../../docs/night-acceptance.md)。
